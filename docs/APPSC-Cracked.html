Part 1

The exam has changed

Until 2019, an APPSC paper was almost entirely direct one-liners: "Who founded…?", "Where is…?". Recall was enough. From 2023 the papers look like UPSC's: statement sets, "which statement is incorrect", matching, Assertion–Reason and chronology. In Group 1 Prelims 2024 Paper I only 15 of 120 questions were direct.

Direct one-linersStatement setsWhich statement is (in)correctMatching / pairsAssertion–ReasonOrder / chronology
What this means
  • Knowing a fact roughly is no longer enough: each statement is a separate true/false test.
  • Elimination now decides marks: in Group 2 Prelims 2024, 31 of 118 questions were statement-based.
  • Practice must be in the new format. One-liner drills build recall; statement drills build accuracy.
Base rate to remember

Across all 983 APPSC statements whose truth the key fixes, 41% were false (41% in 2023–25 papers). So a rule only helps if the statements it picks out are false clearly more often than 41%. Every rule in this guide is measured against that line.

How to use a rule
  1. Answer from knowledge first. A rule never overrides something you know.
  2. When unsure of a statement, check it against the strong rules; each one that fires tilts it toward false.

Rule 1"…but…not…" is a trap Strong · 82% of 17

A statement that sets up a fact and then twists it with but … not ("X is a Fundamental Right but not enforceable") is usually false. Read it as two claims and test the second one hard. The twist is where the examiner plants the error.

Part 3

UPSC rules that don't pay in APPSC

Coaching books built on UPSC teach these as elimination rules. On APPSC's own papers they are false no more often than any other statement — use knowledge, not the rule.

Exact figures 47% false of 173

UPSC students learn "exact data is wrong". In APPSC, statements with exact numbers were false at about the base rate: APPSC does test numbers (seats, percentages, distances, Articles). Learn them; don't eliminate them.

Years and dates 46% false of 110

A precise year is no more likely to be wrong than any other statement. APPSC (especially AP history) asks dates straight.

"The Constitution provides / Article X says…" 46% false of 26

The UPSC habit of distrusting "according to the Constitution" does not pay in APPSC: these statements were false at the base rate. Know the Article.

Named offices (President, Governor, Speaker…) 49% false of 93

The authority-swap trap exists, but overall statements naming an office are false only at the base rate. Use knowledge, not the rule.

Reasons (because / due to / hence) 43% false of 21

A reason in the statement doesn't make it more likely false in APPSC.

Named international organisations 42% false of 24

Statements naming WHO / UNEP / World Bank etc. were more often true than false in APPSC. Don't eliminate on the name alone.

Too rare in APPSC to matter (fired fewer than ten times in all papers): A steady / continuous trend (7×), "X and Y were contemporaries" (1×), "native / endemic / indigenous to" (1×), "legally binding / mandatory / enforceable" (4×), "tax-free / exempt" (1×), A headquarters city (2×).

The play: in a 3- or 4-statement set, settle the statement you are surest of first and strike every option that contradicts it. In Group 1 Prelims, "all four correct" was the key only 13 time(s) in 108 four-statement sets — with nothing else to go on, avoid it. In Group 2 Mains it is more common, so don't apply that there.

Answer position (2023–25 papers)

A: 196 · B: 192 · C: 198 · D: 191 — spread evenly. There is no "safe letter"; never fill blanks by pattern.

Assertion–Reason (36 questions)

both true, R explains A: 19; A true, R false: 7; both true, R doesn't explain A: 5; A false, R true: 3; other: 2. Most often both are true and R explains A — but check that R really is the reason, not just a true sentence.

Matching and chronology

  • Matching: fix the one pair you are surest of, strike every code without it, then fix a second pair: usually one code is left. Don't count on any code shape.
  • Chronology: place the earliest and the latest event first; in APPSC orders the middle two decide fewer options than the ends.
  • "Which one is NOT correctly matched": treat each pair as a true/false statement; the odd one out is often the pair with a swapped place or person from the same family (two Mughal battles, two Satavahana kings).
Part 5

The negative-marking maths

With one-third of a mark taken for a wrong answer, a blind guess on a four-option question is worth exactly zero on average. Every option you can rule out makes guessing pay.

Your situationChance rightExpected marks per questionDecision
Pure guess (no option ruled out)1 in 4+0.00 marksSkip
One option ruled out1 in 3+0.11 marksAnswer
Two options ruled out1 in 2+0.33 marksAnswer
Three ruled out (you know it)1 in 1+1.00 marksAnswer
Rule of thumb

If you can strike one option with a real reason, answer. Strike two, and the question is worth a third of a mark on average. Over 20 such questions that is about 7 marks — often the cut-off margin.

When not to guess
  • All four options look equally possible (expected value zero, variance only).
  • The "reason" you struck an option with is a rule from Part 3 (no edge, or reverse).
  • You're changing an answer you got from knowledge on a gut feeling.

Using the rules together

  1. Statements you know: mark them T/F.
  2. Statements you don't: check Rules 1–7. Two or more firing = lean false; a reversal pattern (first/largest, AP fact, packed statement) = lean true.
  3. Strike the options that disagree with your T/F marks. If two options remain, the question is worth about +0.33 marks: answer.

Current Affairs: the window and the AP share

  • Window: every dated Current Affairs question in Group 2 Prelims 2024 (Feb 2024) was about 2023–24 events — the last 12–15 months before the exam, plus events announced for the coming year (e.g. the 2025 Asian Winter Games).
  • AP share: 6 of 30 Current Affairs questions in Group 2 Prelims 2024, and 9 of 30 in Group 1 Prelims 2023, were about AP. AP schemes, appointments, awards, investments and firsts are a guaranteed block.
  • Angles asked: awards (who / field / edition), appointments, summits (venue, host, edition, theme), sports winners, firsts, schemes (ministry, target group), reports (publisher, India's / AP's rank). Statement sets on one event (e.g. Asian Winter Games 2025: venue, slogan, mascots, emblem) are now common — learn 3–4 facts per big event, not one.

Group 2 Mains 2025: the balance

Paper I = AP history (75) + Constitution (75); Paper II = Economy with AP economy (75) + Science & Technology (75). About half of Paper I and a quarter of Paper II were statement, matching or A–R questions — study AP history and the Constitution at statement depth (who, when, which Article, what exactly), not headline depth.

Part 7

Exam-day method

Three passes

  1. Pass 1 (about 60% of the time): answer everything you know. Mark "?" on questions where you can strike at least one option, skip the rest.
  2. Pass 2: return to the "?" questions. Apply the statement rules and the option structure; answer when two options or fewer remain.
  3. Pass 3 (last 10 minutes): fill the OMR / review. Don't change knowledge answers on a feeling.

Reading a statement set

  1. Read the question line first: correct or incorrect? (About one in seven statement questions in the 2023–25 papers asks for the incorrect ones — easy to misread under time.)
  2. Mark each statement T / F / ? in the margin.
  3. Look at the options before deciding the "?" ones: often they no longer matter.

Trap words to circle

Lean false: only · but…not · always / never / all / none / every · whereas / unlike / more than · not / no / did not · main / primary aim · launched / set up by (check the body).

Do NOT lean false: exact figures · years · "Article X" · international organisations · named offices · reasons.

Lean true in APPSC: first / largest / oldest · AP-specific facts · long statements packing several facts.

Preparation that matches the new paper

  • Revise every topic as true/false statements, not only as one-liners: for each fact, know the likely twist (swapped body, year, place, number).
  • For AP history and the Constitution, keep "pairs" lists (ruler–capital, Article–subject, scheme–ministry): matching questions are built from them.
  • Practise 4-statement sets under time; aim for one decided statement per question before looking at options.
  • Current Affairs: 12–15 months back, AP first; for each big event, 3–4 facts.

Cheat sheet

Lean FALSE

  • "... but ... not ..." — 82% false
  • The word "only" — 75% false
  • Extreme words — 58% false
  • A comparison (whereas / while / unlike / more than / higher than) — 62% false
  • A statement that itself says "not / no" — 61% false
  • "launched / set up / implemented by" a body — 60% false
  • "main / primary / chief aim" — 58% false

No edge — use knowledge

  • Exact figures (not years)
  • A precise year or date
  • "The Constitution defines / provides / mentions ..."
  • A named office (President, Governor, Speaker, CM ...)
  • A reason given (because / due to / hence / so)
  • A named international organisation

Lean TRUE in APPSC

  • "first / largest / highest / oldest" claims — only 31% false
  • Andhra Pradesh-specific claims — only 35% false
  • Two or more facts joined in one statement — only 37% false

Statement sets

  • 3 statements: exactly 2 true is most common (58% in Group 1 Prelims).
  • 4 statements: 2 or 3 true (63%); all 4 rare in Prelims (12%).
  • Decide the surest statement first; strike options that contradict it.
  • Check "correct" vs "incorrect" in the question line before marking.

Options

  • All of the above: key only 28% of the times it appears — never a default.
  • None of the above / neither: key in 39% — don't dismiss it.
  • Four numbers: a middle value 64% of the time.
  • Straight a-I, b-II… code: chance only. Answer letters: evenly spread.

Guessing (−⅓ per wrong answer)

  • Blind guess: 0 expected marks — skip.
  • One option struck: +0.11 — answer.
  • Two struck: +0.33 — answer.

Study priorities

  • Every section carries a fixed 30 (Prelims) / 75 (Mains): none can be skipped.
  • ~1 in 5 questions repeats a fact area — mostly from other State PSCs.
  • Current Affairs: last 12–15 months; about a quarter on AP.

Built from APPSC papers 2008–2025 and their keys; percentages are from those papers only. Rules are probabilities: when you know the fact, the fact wins.
