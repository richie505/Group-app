## U0703 | NETWORKS AND THE INTERNET – LAN/WAN, PROTOCOLS, IP, DNS, WEB TECHNOLOGIES
### 1. INTERNET – BASICS AND HISTORY
- The **Internet** is "a **network of networks**", connected by **TCP/IP**; it is a global **WAN**.
- **DNS** is the internet's directory: it turns **domain names into IP addresses**.
#### 1.1 Internet Firsts – Timeline
| Year | Event |
|---|---|
| 1969 | **ARPANET**, built under the **US Department of Defense** – forerunner of the internet |
| 1984 | **OSI model** ratified |
| 1986 | **ERNET** – academic network of India |
| 1989 | **WWW** invented by **Tim Berners-Lee** at **CERN** |
| 1994 | **W3C** founded by Tim Berners-Lee |
| 1995 | **VSNL** launched public internet in India on **15 August 1995** |
| 1998 | **Satyam Infoway (Sify)** – **first private ISP** of India; **ICANN** set up |
| 2003 | **NIXI** set up under MeitY |
| 2022 | **BhashaNet** launched (MeitY-NIXI) |
| 2023 | **Telecommunications Act** replaced the Indian Telegraph Act, 1885 |
!KEY Order to remember: ARPANET (1969) → ERNET (1986) → WWW (1989) → VSNL public internet (1995) → Sify first private ISP (1998).
#### 1.2 World Wide Web
- **WWW (W3)** = **World Wide Web**: information system for sharing content over the internet, accessed according to **HTTP**.
- A collection of linked information on computers available through the internet.
- WWW is a **hypermedia system** because it links to other computer resources (linked hypertext documents).
!TRAP Internet (network of networks) and WWW (information system on top of it) are not the same thing.
### 2. NETWORK TYPES AND TOPOLOGIES
#### 2.1 Network Types by Scope
| Type | Scope / feature |
|---|---|
| **PAN** | Personal area; personal devices (**Bluetooth**) |
| **LAN** | A building or campus; **Ethernet** is an example (protocol **IEEE 802.3**) |
| **MAN** | A **city** |
| **WAN** | Spans large areas and **links LANs** in different cities; the internet is a global WAN |
| **VPN** | **Virtual Private Network** – an **encrypted tunnel** over the public internet letting users reach their organisation's network safely; improves privacy |
!KEY APPSC 2019: A firm linking LANs in **Mumbai, Bengaluru and New Delhi** uses a **WAN**.
#### 2.2 Topologies
| Topology | Layout | Resilience |
|---|---|---|
| Bus | All nodes on one backbone cable | Backbone break stops the whole network |
| **Star** | All nodes to a central hub/switch | A failed node is only isolated; **hub failure stops all** |
| Ring | Each node linked to two neighbours | One break can disrupt the ring |
| **Mesh** | Every node linked to every other | **Most resilient**; costliest – **n(n-1)/2 links** |
| **Tree** | Mix of bus and star | Used by the **Internet** |
| Hybrid | Mix of types | The Internet is the **largest hybrid topology** |
- Common topologies: star, bus, ring, tree, mesh, hybrid.
!TRAP "Which is NOT a common topology?" – **Grid**.
### 3. OSI MODEL AND NETWORK DEVICES
#### 3.1 Seven Layers (top to bottom)
| Layer | Function | Protocols / devices |
|---|---|---|
| 7 Application | User services | HTTP, FTP, SMTP, DNS |
| 6 Presentation | **Encryption, compression**, formats (JPEG) | – |
| 5 Session | Opens and closes sessions | – |
| 4 Transport | End-to-end delivery | **TCP, UDP** |
| 3 Network | Routing; **IP addresses** (Internet layer of TCP/IP) | **Router** |
| 2 Data Link | Framing, **MAC addresses**, error detection; Ethernet, PPP | **Switch, bridge, NIC** |
| 1 Physical | Signals on the medium | Cables, **hub, repeater, modem** |
- The **Data Link layer** lies between the Physical and Network layers.
#### 3.2 Devices
| Device | Job |
|---|---|
| Hub | Broadcasts to **all ports** |
| **Repeater** | Regenerates/**amplifies** a weak signal to extend the network along the cable |
| Switch / Bridge | Forwards frames by **MAC address** |
| Router | Connects different networks; routes by **IP** |
| **Modem** | **Modulator-demodulator**: converts digital → analog **and** analog → digital (both); links a microcomputer with the telephone line to send and get data worldwide |
| Gateway | Joins networks that use **different protocols** |
| **Proxy server** | Middleman passing client requests to other servers; does **not** provide TCP/IP addresses |
| Network server | Powerful central store for shared data and programs |
!PAIR Switch | Layer 2 | MAC address || Router | Layer 3 | IP address
!TRAP The modem is **not** a Transport-layer device; it works at the Physical layer.
### 4. PROTOCOLS
- A **protocol** is a **set of rules that controls data communication**.
#### 4.1 Protocol → Function
| Protocol | Function |
|---|---|
| **TCP/IP** | Set of protocols for all data exchange across the internet; **TCP** makes packets and checks none is missing (reliable delivery); **IP** addresses and routes packets |
| **HTTP** | **Hypertext Transfer Protocol** – used for accessing the WWW; sets how messages pass between browsers and web servers |
| **HTTPS** | Safer than HTTP – **encrypts** browser-server traffic via **TLS** |
| **FTP** | **File Transfer Protocol** – sharing files over the internet |
| **SMTP** | **Sends** e-mail |
| **POP3** | Downloads mail to one device, usually **deletes** it from the server |
| **IMAP** | **Keeps mail on the server**, synced across devices |
| **DNS** | **Domain Name System** – list of names and addresses of internet hosts; name → IP address |
| **DHCP** | Assigns IP addresses **automatically** |
!TRAP SMTP sends; POP3 downloads and deletes; IMAP keeps on server.
#### 4.2 Three Elements of a Protocol
| Element | Meaning |
|---|---|
| **Syntax** | Format of data |
| **Semantics** | Meaning of each field |
| **Timing** | When and how fast data is sent |
### 5. IP AND MAC ADDRESSING
| Address | Length | Notation |
|---|---|---|
| **IPv4** | **32 bits** (~4.3 billion addresses) | Dotted decimal, e.g. 192.168.1.1 |
| **IPv6** | **128 bits** | **8 groups of hexadecimal** separated by colons |
| **MAC** (Media Access Control) | **48 bits** (6 bytes, 12 hex digits) | Unique device identifier programmed into the **NIC**; used at the **data link layer (Layer 2)** |
- IPv4 and IPv6 addresses identify computers on the internet.
#### 5.1 IPv4 Classes (by first octet)
| Class | Range | Use |
|---|---|---|
| A | 1–126 | Large networks |
| **B** | **128–191** | Medium networks |
| **C** | **192–223** | Small networks |
| **D** | **224–239** | **Multicast** |
| **E** | **240–255** | **Experimental** |
!NUM NUMBER GAME: 32 = IPv4 bits; 128 = IPv6 bits; 48 = MAC bits; 8 = hex groups in IPv6.
### 6. TRANSMISSION MODES AND CONNECTIONS
| Mode | Meaning | Example |
|---|---|---|
| **Simplex** | One way | Radio/TV broadcast, keyboard |
| **Half duplex** | Both ways, one at a time | **Walkie-talkie** |
| **Full duplex** | Both ways at once | **Telephone** call |
| Connection | Medium |
|---|---|
| **DSL** (Digital Subscriber Line) | **Telephone copper lines** (voice frequency) |
| Cable internet | **Coaxial** lines of cable TV companies (cable modem) |
| Fibre | **Light pulses** in optical fibre |
| **Dial-up** | **Slowest** – up to **56 Kbps** |
| Satellite internet | Space, ground and user (**VSAT**) segments; needs **no terrestrial wire** |
- "G" in **2G** stands for **Generation** (2nd Generation wireless technology).
- A **podcast** is a radio programme shared via the internet.
### 7. WIRELESS STANDARDS
| Feature | Bluetooth | Wi-Fi |
|---|---|---|
| Standard | **IEEE 802.15.1** (PAN technology) | **IEEE 802.11** (wireless LAN) |
| Band | **2.4 GHz** | **2.4 and 5 GHz** (Wi-Fi 7 also 6 GHz) |
| Range | Short (~10 m, class 2) | Longer, whole building |
- **APPSC 2019 key**: latest Bluetooth version = **5.1** (follow the key for that question).
- Since then: **Bluetooth 6.0** (August 2024) added **Channel Sounding**; **6.1** and **6.2** followed in 2025 under a twice-yearly schedule.
- **Wi-Fi 7** = **IEEE 802.11be**; works in **2.4, 5 and 6 GHz** bands.
- **Wi-Fi Direct**: links devices with no LAN.
- **Li-Fi**: carries data on **LED light**; better bandwidth and security than Wi-Fi.
!TRAP Both Bluetooth and Wi-Fi use the 2.4 GHz band; only Wi-Fi also uses 5 GHz.
### 8. WEB TECHNOLOGIES
#### 8.1 Web Terms
| Term | Meaning |
|---|---|
| **Web server** | Stores webpages (marked up with **HTML** tags – HyperText Markup Language) and **serves** them on request |
| **Web browser** | Requests and **displays** webpages (Chrome, Firefox) |
| **Search engine** | **Indexes** webpages so they can be found (Google, Bing) |
| **Web crawler** | Also a **web spider (spiderbot)**; internet bot that scans the Web for indexing |
| **Home page** | First page a browser shows on opening a website |
| **URL** | **Uniform Resource Locator**; order: **protocol** (`https://`) → **domain name** (`www.example.in`) → **path** to the file |
| E-mail address | **user name + domain name** (username@domainname.extension) |
| **.edu.us** | An educational institute in the USA (.us = United States, .edu = education) |
| **Web 3.0** | Third generation of the web – changes how the web is used, how sites are managed and how services are delivered |
| **JSP** | **Java Server Pages** – web pages made live; released **1999** by **Sun Microsystems** |
| OCEN | Open Credit Enablement Network – aims to democratise lending so small borrowers get the best credit terms |
- **W3C** (World Wide Web Consortium): main international **web standards body**; founded **1994** by **Tim Berners-Lee**; keeps pages working the same across browsers.
- Core front-end technologies: **HTML5, CSS3, JavaScript**.
!PAIR Browser | displays pages | Chrome || Server | stores and serves pages | Network server
#### 8.2 Browsers vs Search Engines
| Name | What it is |
|---|---|
| **Yahoo** | **Search engine**, not a web browser |
| **Baidu** | Chinese search engine |
| **DuckDuckGo** | Search engine that does **not collect user information** |
| **Bing** | Search engine of **Microsoft** (2009) |
| **Chrome** | Web browser by **Google** (2008) |
| Internet Explorer (now **Microsoft Edge**), Firefox, Opera, Vivaldi | Web browsers |
| **Google Apps** | **Not** a web browser |
| **Orkut** | Closed social networking site, **not** a search engine |
#### 8.3 Layers of the Web
| Layer | Share | Features |
|---|---|---|
| Surface (clear) web | ~4-5% | **Indexed** by search engines |
| **Deep web** | **~90-95%** | Not indexed – e-mail inboxes, net banking, intranets; **not always harmful** |
| **Dark web** | Small hidden part of the deep web | Needs **Tor / I2P**; anonymous; linked with illegal markets |
### 9. INTERNET GOVERNANCE AND INDIA
| Body / Act | Year | Role |
|---|---|---|
| **ICANN** | 1998 | US non-profit; manages the global **Domain Name System** and **IP address allocation** |
| **NIXI** (National Internet Exchange of India) | 2003 | Not-for-profit under **MeitY**; runs internet exchange points, the **.in registry** and **IRINN** (IP addresses) |
| **BhashaNet** | 2022 | **MeitY and NIXI** (not ICANN) – **Universal Acceptance** for Indian languages; **.Bharat** in Devanagari |
| **IT Act, 2000** | 2000 | **Sections 69A and 79** – government can order ISPs and intermediaries to block content |
| **Telecommunications Act, 2023** | 2023 | Replaced the **Indian Telegraph Act, 1885**; holds the power to **suspend internet services** |
- **Universal Acceptance**: every app and e-mail system accepts all domain names and e-mail IDs, including those in Indian scripts (internationalised domain names).
- **7 Apr 2026**: a site opening on one ISP but not another is due to ISP-level **DNS poisoning, HTTP interception or SNI filtering** (on HTTPS); blocklists differ across ISPs.
- **Economic Survey 2025-26**: internet connections rose from **25.15 crore (2014)** to **96.96 crore (2024)**; **BharatNet** fibre reaches **2.18 lakh gram panchayats**.
- **AP angle (29 Jun 2026)**: CM **Chandrababu Naidu** and **Sunil Mittal** discussed **last-mile connectivity, data centres and an undersea cable landing station** for Andhra Pradesh.
