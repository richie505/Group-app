## U0708 | BIG DATA, CLOUD COMPUTING, EDGE COMPUTING AND DATA CENTRES
### 1. BIG DATA
- **Big data** = large volumes of **high-velocity, complex and variable** data (APPSC 2019 key).
- Classic three Vs: **Volume, Velocity, Variety**; **Veracity** and **Value** added later.
| Term | Meaning |
|---|---|
| Data mining | Finding patterns in large datasets |
| **Data warehouse** | **Cleaned, structured** data for analysis |
| **Data lake** | **Raw** data in **native format** |
| Metadata | Data about data |
### 2. CLOUD COMPUTING
- Hosted services (storage, computing power) over the internet **on demand**.
- Five features: **on-demand self-service, network access, metered use, elasticity** (resources grow/shrink with demand), **resource pooling** (shared resources).
| Model | User gets | Example |
|---|---|---|
| **IaaS** | Servers, storage, network | **Amazon EC2** |
| **PaaS** (Platform as a Service) | Platform to develop, deploy, run, manage apps | **Google App Engine** |
| **SaaS** | Ready software over the web; mobile access, customisable | **Outlook, Gmail** |
- Deployment: public, private, hybrid, community. Providers: AWS, Microsoft Azure, Google Cloud.
| Storage service | Company |
|---|---|
| **SkyDrive (now OneDrive)** | **Microsoft** |
| **S3** | **Amazon Web Services** |
| Google Drive / iCloud / Dropbox | Google / Apple / Dropbox Inc. |
!TRAP **"Hardware as a Service"** is not a separate layer (comes under IaaS); **spectrum allocation** is not a cloud service.
### 3. EDGE, FOG, SERVERLESS AND CONTAINERS
| Model | Where | Feature |
|---|---|---|
| Cloud | Distant central data centres | Heavy storage, analytics |
| Fog | Between edge and cloud | Local aggregation |
| **Edge** | On/near device | **Lowest latency**; saves bandwidth; keeps private data local |
- **Virtualisation**: one server runs many VMs, **each with its own OS**.
- **Containers** (Docker): lighter, **share the host OS kernel**.
- **Serverless**: provider runs and scales servers, billing per use (AWS Lambda).

### 5. DATA CENTRES
- Capacity: **375 MW (2020) → 1.57 GW (2026) → ~8 GW (2030)**. **Mumbai 52%**, then Chennai, Delhi NCR, Bengaluru.
- **PUE** = total facility energy ÷ IT energy; **closer to 1 = better**.
- **Uptime Tier IV**: fully fault-tolerant, **~99.995%**; Tier I basic.
- **Draft Data Centre Policy (Sep 2025)**: **20-year** tax holiday (not 10).
- Data centres use ~1% of global electricity; cooling needs much water.
#### 5.1 AP – Visakhapatnam Hub
- Projected **India's biggest hub, ~6 GW over 10 years**; Vizag–Kapuluppada corridor.
- Advantages: **submarine cable landing**, **sea-breeze cooling**, **Seismic Zone II**, nearness to **Southeast Asia** (not EU).
- Investors: **Google** (**$15 billion**, 1 GW AI hub, Oct 2025), Reliance, **TCS (HyperVault)**, CtrlS, GMR.
