## U0702 | NATURE AND SCOPE OF ICT; HARDWARE, SOFTWARE, MEMORY AND OPERATING SYSTEMS
### 1. NATURE AND SCOPE OF ICT
- **ICT = Information and Communications Technology**: umbrella term for any device or application used to **access, store, transmit and manipulate digital information** – mobiles, networks, software, internet, satellites; access to information through telecommunications (internet, wireless networks, cellphones).
- Aim: smooth **human-human, human-machine and machine-machine (M2M)** communication.
- Concerns: privacy risks, **digital divide**, job insecurity, over-reliance on technology.
- A computer's strengths – **all of**: high speed, accuracy and memory (temporary and permanent).
- **Artificial Intelligence** boosts human abilities by making machines intelligent and mimicking human actions.
- **Cybernetics**: study of automation and communication between human and machine – term by **Norbert Wiener**.
- **Technology preservation** = computer museum (APPSC 2019).
- **Aarogya Setu, CoWIN, DigiLocker, DIKSHA** – all four built on **open-source digital platforms**.

### 3. COMPUTER TYPES
| Type | Feature / example |
|---|---|
| **Analog** | Continuous quantities – **car speedometer**, thermometer |
| **Digital** | Discrete (binary) data – PCs |
| **Hybrid** | Both – ICU monitors, ECG |
| **Personal / micro** | Desktop, laptop, tablet, smartphone, wearables (smartwatch, fitness tracker, AR glasses) |
| **Embedded** | Dedicated function inside a larger system – **digital watch** |
| **Supercomputer** | **Largest, fastest and costliest**; speed in **FLOPS** |
| **Quantum computer** | Uses **qubits** (superposition, entanglement); fast calculation, cryptography, optimisation |
- **Fax and email over phone lines** use **both analog and digital** signals.
- Quantum computer is described as the smallest and fastest computer copying brain working. Oxford University researchers made **10 billion quantum entanglements** in silicon.
- **Q-Day**: when quantum computers may break **RSA-2048** encryption using **Shor's algorithm (1994)**.
### 4. HARDWARE – CPU AND COMPONENTS
#### 4.1 CPU
- **CPU = Central Processing Unit** (NOT "Control Processing Unit") – the **brain** and most important part; most calculations happen here.
| Component | Function |
|---|---|
| **ALU** (Arithmetic Logic Unit) | Arithmetic and logical operations; calculations and decisions |
| **CU** (Control Unit) | **Fetches and decodes** instructions, makes control signals, directs |
| **Registers** | **Fastest** storage inside the CPU |
| **PSU** | Only supplies power |
- After a **double-click** of the mouse, information goes to the **CPU**.
- Main components: input/output devices, processing unit, memory unit, secondary storage – **"basic unit" is not a component**.
#### 4.2 Processors and Power
- **Celeron, Pentium, Core** = series of processors; **Intel Core i9** = high-end CPU with **8 to 24 cores**; multi-core CPUs.
- **IBM = International Business Machine(s)**.
- **UPS = Uninterrupted Power Supply** – keeps the computer running briefly when power fails.
- **SMPS = Switched Mode Power Supply** – changes rectified AC input into low-voltage DC.
- **Modem** – hardware linking telephone lines and computer equipment.

### 6. MEMORY AND STORAGE
#### 6.1 Units in Order
- **Bit** (binary digit) = smallest unit; memory is measured in bits. **Nibble = 4 bits**; **byte = 8 bits** (APPSC 2025).
- Order: bit < nibble < byte < **KB** < MB < GB < TB < PB < EB < ZB < YB.
| Unit | Equals |
|---|---|
| 1 byte | 8 bits |
| 1 KB | 1024 bytes = **8192 bits** |
| 1 MB | 1024 KB |
| 1 GB | 1024 MB |
| 1 TB | 1024 GB |
!TRAP Smallest of the units asked (KB, MB, GB, TB) = KB.
#### 6.2 Primary Memory
| Memory | Nature |
|---|---|
| **RAM** (Random Access Memory) | **Volatile**, temporary working store, lost when power goes off; **SRAM = cache**, **DRAM = main memory** |
| **ROM** (Read-Only Memory) | **Non-volatile**, permanent, can only be read; holds firmware/**BIOS** (Basic Input-Output System); PROM, EPROM, EEPROM |
| **Cache** | Small, **fastest** memory between CPU and RAM; shortest access time, highest bandwidth; speeds up processing |
| Memory | Erased by |
|---|---|
| **EPROM** | **Ultraviolet light** |
| **EEPROM** | **Electrically** |
- **ROM is a memory, not a computer language.**
- Memory types: **semiconductor** (primary), **magnetic** and **optical** (secondary) – "server" is not one.
#### 6.3 Secondary Storage
| Storage | Fact |
|---|---|
| **HDD** | Magnetic disk; non-volatile |
| **SSD** | **Flash** memory, **no moving parts**, faster |
| **Magnetic tape** | **Sequential access**, slowest; backup and archival |
| **Flash drive / memory card** | EEPROM-based flash; keeps data without power; **not cheaper** than mechanical disks |
| CD | about **700 MB** |
| **DVD** | **4.7 GB** single layer; 8.5 GB dual layer |
| **Blu-ray** | **25 GB** single layer; 50 GB dual layer |
- **RAM is NOT secondary memory**; SSD, hard disk and USB pen drive are.
- Magnetic tape and magnetic disk both store very large data; the **disk stores more**.
!NUM Speed order: registers > cache > RAM > SSD > HDD > optical disc > magnetic tape
### 7. SOFTWARE TYPES
- **Software** = another name for computer programs; two major types: **application** and **system**.
| Type | Examples |
|---|---|
| **System software** | OS, **device drivers**, translators (**compiler**, interpreter, assembler) |
| **Utility software** | Antivirus, disk cleanup, backup, compression |
| **Application software** | **MS Word**, spreadsheets, photo/video/audio editing, DTP, CAD, browsing, gaming; **graphics** (Photoshop, CorelDRAW); **multimedia** (players, editors); **database** (Oracle, MySQL, MS Access); **MS Outlook** (e-mail, calendar, contacts) |
- **Device driver** = system software, not application.
- **Word processing software**: Microsoft Word, **WordStar** (MicroPro International) – all options given are correct.
- **Microsoft Office** = office suite (Word, Excel, PowerPoint), **not an OS**.
- **Multimedia**: text joined with audio, video, voiceover, animation and graphics in one digital presentation.
- **Compiler** and **assembler** are **not hardware** – they are programs.
- A Word document, video or MP3 is a **file**; the **extension** shows its type (.doc = Word).
#### 7.1 Open Source
- **Open-source**: source code free to view, modify and share under its licence (unlike proprietary).
- **GNU ("GNU's Not Unix")**: free, **Unix-like** OS software, so compatible with Unix; **Linux** kernel by Torvalds.
- **Internet Explorer** = **closed source**.
### 8. OPERATING SYSTEMS
- **Functions**: manages hardware; gives user interface; handles processes, memory, file systems, device drivers, security and I/O.
| OS type | Feature / example |
|---|---|
| **Time-sharing / multi-user** | Many users share CPU time – **UNIX** |
| **Real-time** | Fixed response deadlines – **missile guidance, air-traffic control**, medical devices (hard vs soft) |
| **Mobile** | **Android** (Linux-based, Google), **iOS** (Apple), **BharOS** (IIT Madras) |
#### 8.1 Interfaces and Examples
| Interface | Example |
|---|---|
| **CLI** (command-line, non-graphical) | **MS-DOS**, UNIX shell |
| **GUI** (icons, windows, mouse) | Windows, macOS |
- **MS-DOS**: Microsoft, **August 1981**; written by **Tim Paterson** from 86-DOS, for IBM-compatible PCs; eight versions.
- **UNIX**: multi-user OS, made **1969** by **AT&T**; **kernel** = main part; UNIX = kernel + shell + commands + applications.
- **Windows 3** – 1990; **Windows 11** – October 2021.
- **Android 6.0 = Marshmallow** (shown May 2015, released October 2015).
- **Linux, Windows, Unix** = OSs; MS Office is not.
### 9. PROGRAMMING, NUMBER SYSTEMS AND LOGIC
#### 9.1 Language Levels
| Level | Fact |
|---|---|
| **1GL machine language** | Only **0 and 1**; the only language a computer runs directly; **no translator**; machine code; based on **Boolean algebra** |
| **2GL assembly** | **Mnemonics**; converted by an **assembler** (not a compiler) |
| **3GL high-level** | **FORTRAN** (Formula Translation, IBM, scientific, first HLL 1957), **COBOL** (business), **BASIC** (Beginner's All Purpose Symbolic Instruction Code), PASCAL, C, C++ (Stroustrup), Java, Python |
- **BASIC** is a **procedural** language (with C, FORTRAN, PASCAL).
- **Cobra, Python, Squirrel, Java** are all computer languages; **Paint brush** and **FAST** are NOT.
- APPSC 2019 odd-one-out answer: **Python**.
#### 9.2 Translators and Logic Design
| Term | Meaning |
|---|---|
| **Compiler** | System software; translates the **whole program** at once (faster execution) |
| **Interpreter** | Translates and runs **line by line** (easier debugging) |
| **Algorithm** | Finite step-by-step procedure |
| **Flowchart** | **Pictorial** form of an algorithm (APPSC 2019) |
| **Pseudocode** | English-like text outline |
| Source code | The written program |
- Flowchart symbols: **oval** = start/end, **parallelogram** = input/output, **rectangle** = process, **diamond** = decision.
#### 9.3 Number Systems
- Binary (base 2), octal (8), decimal (10), **hexadecimal** (16, digits 0–9 and A–F).
- (1010)₂ = 10; **(FF)₁₆ = 15 × 16 + 15 = 255**.
#### 9.4 Logic Gates and Boolean Algebra
- **Universal gates: NAND and NOR**; basic gates: AND, OR, NOT.
- **OR**: output 1 if any input is 1; 0 only when all inputs are 0. **XOR**: 1 when inputs differ.
- Boolean: A + A = A; A·A′ = 0; **De Morgan: (A + B)′ = A′ · B′**.
