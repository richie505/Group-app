## U0719 | CYBER SECURITY CONCERNS – CYBER CRIME TYPES, MALWARE, RANSOMWARE, PHISHING, SOCIAL ENGINEERING
### 1. MALWARE – TYPES AND MECHANISM
- **Malware**: software designed to disrupt, damage or gain unauthorised access to a computer system.
- **VIRUS** = "**Vital Information Resources Under Siege**"; a program that can **replicate itself** and spread computer to computer.
#### 1.1 Malware Types → Mechanism → Example
| Type | Defining behaviour | Example |
|---|---|---|
| **Virus** | Attaches to files; **user must run** the infected file | Brain, Michelangelo |
| **Worm** | **Self-replicates** across networks **without user interaction**; fastest spreading | WannaCry |
| **Trojan** | **Disguised** as genuine software; **no self-replication**; opens a **backdoor** | Zeus |
| **Ransomware** | **Encrypts files**, demands ransom (often crypto) | AIIMS Delhi (2022) |
| **Spyware** | **Secret surveillance**; steals passwords, banking data | Pegasus |
| **Adware** | Unwanted ads; bundled with free/pirated software | Fireball |
| **Rootkit** | Administrator-level access; **hides other malware**; hardest to detect | Stuxnet parts |
| **Keylogger** | **Records keystrokes** (passwords, PINs, OTPs) | DarkHotel |
| **Botnet** | Network of hijacked **"zombie"** devices for **DDoS**, spam, crypto-mining | **Mirai** (IoT) |
- Trojan: looks genuine, tricks the user into installing it, then acts like a virus or worm.
!TRAP "Self-replicating without user action" = worm; "no self-replication, disguised" = trojan.
!PAIR Rootkit | Hides | Other malware || Keylogger | Records | Keystrokes
### 2. NAMED MALWARE AND FIRSTS
| Name | Type | Origin / note |
|---|---|---|
| **Creeper** (1971) | **First** self-copying program/virus | **ARPANET** (Bob Thomas, BBN); removed by **Reaper** |
| **Elk Cloner** (1982) | First virus **"in the wild"** | **Apple II**, Rich Skrenta |
| **Brain** (1986) | First **IBM-PC** boot-sector virus | Alvi brothers, **Lahore, Pakistan** |
| **Michelangelo** | Virus | Made to infect MS-DOS on **6 March 1992**; first found in **Australia** (1991) |
| **Stuxnet** (2010) | **Worm** with rootkit parts | Sabotaged Siemens PLC-controlled **uranium centrifuges** at **Natanz, Iran**; targets industrial control systems |
| **Petya** (2016) / NotPetya (2017) | **Ransomware** | Encrypts the **master boot record**; NotPetya hit Ukraine |
| **WannaCry** (May 2017) | **Ransomware** spreading as a **worm** | Used **EternalBlue**; attributed to North Korea's Lazarus group |
| **EternalBlue** | Exploit of a **Windows SMB** flaw | Developed by **US NSA**; leaked by Shadow Brokers (2017) |
| **StrandHogg** (2019) | **Android** vulnerability | Malware poses as genuine apps; found by Norwegian firm Promon |
| **Pegasus** | **Zero-click spyware** | **NSO Group, Israel**; uses zero-days |
| **Mirai** | **Botnet** | Hijacked IoT devices for large DDoS |
- CERT-In flags (2014): Hikti, Dyreza Trojan, Shellshock.
!KEY APPSC G2 2025: Petya and WannaCry are related to **ransomware**.
### 3. ATTACK TECHNIQUES AND CYBER THREATS
| Threat | Meaning |
|---|---|
| **Phishing** | False e-mails/texts that look legitimate, tricking users into revealing sensitive info or installing software |
| **Vishing** | Phishing by **voice calls** |
| **Spam** | Junk / unsolicited bulk e-mail |
| **E-mail bombing** | **Same e-mail sent repeatedly** to one address to overflow it |
| **Spoofing** | E-mail **appears from one source but is sent from another** (faked e-mail ID, caller ID, IP) |
| **Man-in-the-middle** | Secretly **intercepts/alters** communication between two parties |
| **DoS / DDoS** | **Flooding** a server with fake traffic so genuine users cannot access it; DDoS uses many machines (botnet) |
| **SQL injection** | Malicious database code via website **input fields** |
| **Zero-day** | Exploits an **unknown, unpatched** flaw ("zero days" to fix); e.g. Pegasus |
| **Supply-chain attack** | Compromise a trusted vendor, e.g. **SolarWinds (2020)** |
| **Social engineering** | Manipulating people (**trust, urgency, curiosity**); now AI-enabled |
- **DOS** in cyber law = **Denial of Service**.
- Cybercrime includes **hacking, cyberstalking and DoS attacks**; **online chatting is not a cybercrime**.
### 4. CYBER CRIMES AGAINST PERSONS
| Crime | Modus operandi / law |
|---|---|
| **Digital arrest** | **Not a real police power**; criminals pose as police/CBI on **video call**, "arrest" the victim and extort money |
| **Cyber slavery** | **Trafficking people** and forcing them to run cyber fraud from **scam centres** |
| **Identity theft** | **IT Act Sec. 66C** |
| **Sextortion** | Blackmail with intimate images; **66E/67A** |
| **Dark web** | Hidden internet reached via **Tor**; illegal marketplaces, hacking tools, data dumps |
- First: per **INTERPOL**, **Telangana** police registered one of India's **first cases of human trafficking** to force victims into cyber fraud.
- Scam centres linked to **Myanmar and Laos** (MEA 2025); **FIU-India** flagged **Rs 800 crore** cross-border laundering.
- **Supreme Court**: Centre, States, RBI and telecom authorities to frame **SOPs**, use **zero FIRs**, return victims' money.
- Digital-arrest complaints on NCRP: 1,23,672 (2024) to 58,249 (2025); 16,377 till 30 Jun 2026.
!TRAP Digital arrest is a scam term, not police tracking of criminals.
### 5. FINANCIAL CYBER FRAUDS
| Fraud | Modus operandi |
|---|---|
| **SIM swap** | Duplicate SIM to intercept **OTPs**; fraudster poses as bank official |
| **UPI / QR fraud** | QR code is scanned **only to pay, never to receive** |
| **Loan app / crime-as-a-service** | Syndicates rent out ransomware and fraud tools |
| **Crypto-jacking** | **Secretly using a victim's device to mine cryptocurrency** |
- Cyberabad police arrested 6 from West Bengal for a **Rs 77.75 lakh** SIM-swap racket.
### 6. INFORMATION SECURITY PRINCIPLES AND CYBER INSURANCE
#### 6.1 CIA Triad
| Principle | Threat |
|---|---|
| **Confidentiality** | Exposure; procedures and controls guarding data against illegal access |
| **Integrity** | Alteration |

### 7. CRYPTOGRAPHY TERMS
- **Cryptography**: encoding data so only authorised parties can read it.
| Term | Key point |
|---|---|
| **Encryption / decryption** | Plaintext to ciphertext and back using a key |
| **Symmetric** | **Same key** encrypts and decrypts – **AES**, **Blowfish** (Bruce Schneier, 1993; faster alternative to DES) |
| **Asymmetric** | **Public-private** key pair – **RSA**; basis of **PKI** |
| **Digital signature** | Made with sender's **private key**, verified with **public key**; proves origin and integrity |
| **Hashing** | One-way, fixed-length digest (e.g. **SHA-256**); small change alters the hash |
### 8. SECURITY TOOLS
| Tool | Function |
|---|---|
| **Firewall** | Watches incoming/outgoing traffic by rules; **blocks unauthorised network access**; hardware, software or both |
| **Antivirus** | Prevents and heals infections |
| **MFA / 2FA** | Two independent proofs: **password + OTP/biometric** |
| **Honeypot** | **Decoy** system to trap attackers and study methods |
| VPN, virtual keyboard | Hide traffic; defeat keyloggers |
- Indigenous: **M-Kavach** (mobile security) = **C-DAC Hyderabad**; **CERT-In** = CVE Numbering Authority for products made in India.
!TRAP Firewall = blocks unauthorised access; antivirus = removes infections.

### 10. CYBER WARFARE, EMERGING THREATS AND DATA
- **Cyber espionage**: often **state-sponsored** (APT groups); spear-phishing, zero-days. Most targeted: US, Ukraine, Israel, India.
- **Cyber terrorism**: aims at critical infrastructure; source-tracing hard (**VPNs, proxies, botnets**).
- Emerging: **AI-powered malware** evading antivirus; autonomous agents undermining **Zero Trust**; deepfakes; ransomware-as-a-service.
- **MeitY 2nd Digital Threat Report 2025-26** (BFSI): 6 of 7 earlier predictions came true; shift to social engineering, credential theft, supply-chain and cloud attacks.
- **Exercise Cyber Suraksha**: **DRDO**-led, **12 days**, armed forces.
