### Reform generations — types, areas and factor markets — First vs second generation
## 1. First vs second generation
| First generation (1991-2000) | Second generation (2000s onward) |
| Tariff cuts, removal of import licensing | Factor markets: land, labour, capital |
| Industrial delicensing, FDI automatic route | Public sector and oil sector reforms |
| Financial sector opening, interest-rate deregulation | Reform of government and public institutions; labour and company law; CCI and sector regulators |
- First generation (1991): Delicensing (now only 6 industries), MRTP reform, FDI up to 51%
- Second generation: Deeper institutional reforms
- Areas: Factor markets (land, labour, capital), public sector, government and public institutions, legal system (IPC/CrPC, labour and company law), fiscal
- Sectors: Oil, power, telecom; regulators and the CCI strengthened (UPSC notes p.51)
- ⚠ Trap: Legal System Reforms is NOT in the Government's second-generation list (UPPSC 2009 key) – Oil sector, Public sector, Government/public institutions were; UPSC notes do mention penal and procedural code reforms – follow the key
- Third generation: Making Panchayati Raj Institutions fully functional
- Exam angle: UPPSC 2009 key treated "Legal System Reforms" as NOT on the government's list (Oil sector, Public sector, Government/public institutions were), though UPSC notes include it; follow the key if the options recur.

| Code | Laws merged / subsumed |

### Four Labour Codes → key provisions and expected gains
## 1. Key provisions
| Code | Provisions |
| Code on Wages | Universal minimum wage; Centre fixes a national floor wage; 50% rule on allowances for PF/gratuity/bonus; no gender discrimination incl. transgender persons; 2026 Rules: 8-hour day, 48-hour week |
| IR Code 2020 | Fixed-term workers get parity + gratuity after 1 year; standing orders only for 300+ workers; prior permission for lay-off/retrenchment/closure raised from 100 to 300 workers |
| Social Security Code | 26-week maternity leave; crèche at 50+ employees |
- IR Code: Unions call this hire-and-fire (12 Jun 2026)
- ⚠ 300 = IR Code threshold; 50+ = crèche; 500+ = OSH safety committee
## 2. Precursor — 2018 Standing Orders rules
- Industrial Employment (Standing Orders) Central (Amendment) Rules, 2018:
- Fixed-term employment in all sectors
- No notice of termination needed for a temporary workman
## 3. Expected gains
- Expected gains (ES 2025-26): Formalisation from 60.4% to 75.5% + 1.25% GDP gain by 2029-30 (13 Mar 2026)
### GST as reform → Amendment, Articles, committee, structure
## 1. Constitutional basis — Articles
| Article | Provides for |
| 246A | Empowers Parliament and State Legislatures to levy GST; inserted by the 101st Constitution Amendment Act, 2016 (assent 8 Sep 2016) |
| 269A | The levy and collection of IGST on inter-State supplies (and imports) |
| 279A | The GST Council (some notes say Art. 279) |
| 366(12A) | The constitutional definition of GST |
| 286 | Restrictions relating to taxation of supplies outside a State and import-export |
- In force: 1 July 2017
- Origins: Vijay Kelkar Committee; Canadian model; first to ratify Assam
- ⚠ 246A = power to levy GST; 269A = IGST; 279A = GST Council
## 2. Structure
- Nature: Destination-based consumption tax with input tax credit → ends cascading
- Subsumed (Centre): Central excise, service tax, CST
- Dual GST:
- IGST on inter-state supply and imports
## 3. GST 2.0
- Next-Generation GST (GST 2.0): Announced on the 79th Independence Day (Aug 2025)
- Rate rationalisation
- 40% slab for sin/luxury goods
