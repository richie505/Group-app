### Agents and landforms; weathering and mass wasting types
## 1. Agents and landforms
| Agent | Landforms |
| Running water | Deltas, V-shaped valleys, gorges, meanders, alluvial fans; also canyon, levee, peneplain |
| Glaciers | Cirques, arêtes, horns, U-shaped valleys, hanging valleys; with marine submergence — fjords; also moraine, till, esker |
| Wind | Sand dunes, yardangs, mushroom rocks; also loess |
| Karst or groundwater | Sinkholes, stalactites; also doline, stalagmite (solution in limestone) |
| Waves | Sea caves, sea arches, sea stacks; also cliff (sea cliff), bar (waves and currents) |
| Longshore drift | Spits |
| Tectonic faulting | Rift valleys, horsts, grabens |
- Exam angle: APPSC-G2 2023 matched Delta - running water, Cirque - glaciers, Cliffs - waves and currents, Sand dunes - winds.
## 2. Weathering type → process
| Type | Process |
| Physical | Exfoliation, frost wedging, block disintegration - no chemical change [GK] |
| Chemical | Solution, carbonation, oxidation, hydration, hydrolysis [GK] |
- AP soils from weathering: Granite/gneiss → red soils; basalt → black soils
- Mass wasting: Soil creep, slump, landslide, mudflow, rockfall under gravity
### Valleys → formation
## 1. Valleys
| Valley | Formed by | Notes |
| V-shaped | River erosion | Upper and middle river courses; narrow — in youthful rivers |
| U-shaped | Glacial erosion — glaciers | Glaciers widen and deepen V-shaped valleys — glacially modified valleys have U-shaped cross-sections |
| Hanging | A tributary glacier — less erosive — left above a main valley | A waterfall occurs at the junction of a hanging valley |
| Rift | Crustal faulting or divergence | Death Valley, the Narmada Valley |
| Blind | — | In karst or limestone regions; end abruptly |
### Fluvial landforms → process and river stage; delta type → condition
## 1. River landforms by process
| Landform | Process | Description |
| Waterfall | Differential erosion | A sudden vertical fall |
| Meander | Lateral erosion and deposition | A sinuous river course; Outer bend = erosion, concave cliff-slope vs inner bend = deposition, convex slip-off slope |
| Oxbow lake | Meander cut-off | Crescent-shaped; detached meander loop with stagnant water |
| Floodplain | Deposition | A flat depositional valley floor |
| Natural levees | Deposition | Raised banks along rivers |
| Alluvial fan | Deposition | A cone or fan at a mountain foot |
| Delta | Deposition at river mouths | Accumulates sediment into the sea |
| Estuary | — | A drowned river mouth — a funnel-shaped tidal mouth; freely open to the sea (an ecotone); west-flowing Narmada and Tapi form estuaries, not deltas |
## 2. Stage → landforms
| Stage / course | Landforms |
| Youth (upper course) | V-shaped valley, gorge, canyon, waterfall, potholes, rapids |
| Mature (middle course) | Meanders, flood plains, alluvial fans at the foot of hills |
| Old (lower course) | Oxbow lakes, natural levees, braided channels and riverine islands, deltas |
## 3. Other terms → meaning
| Term | Meaning |
| Canyon | Upper-course feature (APPSC 2022); forms in horizontally bedded sedimentary rocks; step-like sides, wider at the top |
| Gorges | Hard rocks; almost equal width at top and bottom |
| River terraces | Cut by vertical erosion of a stream into its own floodplain; paired = same level on both banks; unpaired = one bank, slow uplift |
## 4. Delta type → condition → example
| Delta type | Condition | Example |
| Arcuate (most common) | Sediment denser than sea water | Nile, Sundarbans (Ganga) |
| Cuspate | Sediment density = sea water | Tiber (Italy) |
| Bird-foot | Sediment lighter than sea water, carried far | Mississippi |
- ⚠ Denser → arcuate; equal → cuspate; lighter → bird-foot
### River-plain terms → meaning and region; plain types
| Term | Meaning / region |
| Bhabar | Coarse gravel-pebble belt (alluvial fans) where Himalayan rivers enter the plains |
| Terai | Marshy, forested belt south of the Bhabar where the streams/water come to the surface again |
| Bhangar | Older, higher alluvium with lime nodules (kankar) |
| Khadar | New alluvium of the active floodplain; fine clay and sand, no kankar |
| Doab | Land between two rivers - Ganga-Yamuna Doab is the westernmost Ganga plain |
| Prayag | Confluence of rivers, e.g. Devprayag (Bhagirathi + Alaknanda: the Ganga begins) |
| Badland / ravines | Chambal valley (APPSC 2022); Chos of Hoshiarpur (Punjab) |
| Karewas (Vudr) | Lacustrine deposits of the Kashmir valley |
| Bet land | Flood plain while floodwater stays on it |
- ⚠ Bhangar = old, with kankar; Khadar = new, no kankar
- Plain types:
- Alluvial: Indo-Gangetic / Indo-Ganga-Brahmaputra plain; most densely populated; India's youngest physiographic division
- Lacustrine: Filled lake beds, e.g. Kashmir Karewas / Kashmir valley deposits
- Peneplain: Near-featureless surface after long erosion; Peninsular plateau = rejuvenated peneplain (rejuvenated at places)
- Till plains: Glacial deposits
- Height: Plains generally below 200 m
### Glacial landforms → formation and meaning
| Landform | Formed by | Description / key point |
| Cirque / corrie | Glacial erosion | A bowl-shaped hollow; armchair-shaped, scooped-out hollow at the valley head |
| Arête | Two cirques eroding a ridge | A knife-edged ridge |
| Horn | Several cirques eroding a mountain | A sharp pyramidal peak (Matterhorn) |
| Fjord | A drowned glacial U-shaped valley | A deep, narrow sea inlet (Norway, Greenland, New Zealand) |
| Moraine | Glacial deposition | Accumulated debris; unsorted glacial debris / mound (till) - lateral (edges), terminal (snout), medial, ground moraines |
| Drumlin | Glacial deposition | A streamlined oval hill; egg-shaped hill of till, long axis parallel to ice flow, blunt end facing the ice |
| Esker | Meltwater deposition | A long winding ridge of stratified sediment marking a sub-glacial tunnel |
| U-shaped valley | Glacier deepens and widens a river valley | Ice moves faster in the centre |
| Hanging valley | Tributary valley left high above the deepened main valley | Stream enters as a waterfall; agent = glacier (UKPSC 2024) |
| Outwash plain | Meltwater streams | Sand and gravel spread out |
- Glacial deposits: Till, moraine and boulder clay = glacial activity (APPSC 2017)
- Drumlin fields: Give "basket of eggs" topography (some notes attach the term to boulder deposits)
- Also: Kettle holes; outwash plain and fjord (drowned glacial valley) as above
- ⚠ Moraine = unsorted; esker = stratified
### Desert (wind) landforms → formation and key point
- Wind transport: Deflation, saltation (bouncing), surface creep
| Landform | Formed by | Description / key point |
| Sand dunes | Wind deposition | Accumulations of sand |
| Barchans | Wind deposition | Crescent-shaped dunes, horns pointing downwind [GK] |
| Seif / longitudinal dunes | Wind deposition | Long, narrow ridges; smaller dunes in groups where sand is scarce |
| Yardangs | Wind erosion | Streamlined ridges; long, steep-sided ridge of soft rock parallel to the wind [GK] |
| Mushroom rocks | Wind abrasion | Narrow bases and wider tops; wind abrades the base more than the top - undercut at the base |
| Deflation hollows | Wind removal | Depressions; wind lifts away loose fine particles |
| Playa | Evaporation or deposition | A dry lake bed; shallow, seasonal salt lake / lake-bed in a desert basin [GK] |
| Loess | Wind deposition | A fine silt deposit; fine wind-blown dust carried far (Loess Plateau of China) [GK]; Plain of Normandy (from glacial outwash), Manchuria (from Mongolia) |
| Zeugen | Wind erosion | Table-like (tabular) ridge: hard cap over soft rock, sides cut away |
- Erosional forms: Mushroom rock, Zeugen, Yardang (see table)
- ⚠ Trap: A "table-like" yardang description fits the zeugen; the yardang is a ridge parallel to the wind
- Other forms:
- Inselberg: Isolated residual hill, e.g. Uluru
### Karst landforms → meaning; speleothems; longest caves
## 1. Karst landforms
- Sinkhole or doline: A closed depression; uvala: coalesced dolines; polje: a large enclosed karst depression
- ⚠ Sources differ: other notes say the doline is a larger depression formed by joining sinkholes (sinkhole → doline → uvala → polje)
- Caves or caverns: Underground dissolution features
- Stalactite: Hangs from a cave roof; stalagmite: rises from a cave floor
- Blind valley: Terminates abruptly; swallow hole: a place where a stream disappears underground
## 2. More on karst
- Karst: Landscape carved by groundwater dissolving limestone/dolomite; named after the Karst region on the Adriatic coast (Slovenia)
- Sequence: Sinkhole (no surface drainage) → doline (sinkholes combined) → uvala (dolines combined) → polje (large depression from cave collapse)
| Feature | Description |
| Sinkhole | Small, deep depression with no surface outlet; water drains underground |
| Doline | Larger depression formed by joining sinkholes; clay can seal it into a doline lake |
| Polje | Large depression from collapse of an underground cave |
| Sinking creek / bogas | Stream lost through cracks; open-topped ones are bogas |
| Blind valley | Valley ending abruptly where its stream vanishes underground into a swallow hole [GK] |
- Cave deposits - speleothems (calcium carbonate):
- Stalactites hang from the cave roof (APPSC 2022)
- Stalagmites rise from the floor
- Meet / joined → pillars/columns
- Longest caves: India = Krem Liat Prah (Meghalaya); world = Mammoth Cave (USA)
### Caves → location → karst or not
## 1. Caves → location → karst or not
| Cave | Location | Nature / type / fact |
| Arwah | Meghalaya (Sohra) | Limestone caves with fossils (APPSC 2018) |
| Belum | Nandyal district (older notes: Kurnool) | Karst: black limestone, stalactites and stalagmites; 2nd-longest natural cave system in India (after Krem Liat Prah, Meghalaya); first discovered 1884 by Robert Bruce Foote, mapped by H.D. Gebauer (1982-84); Patalaganga |
| Borra | Ananthagiri (Anantagiri) hills, Araku, Alluri Sitharama Raju district | Limestone karst caves with stalactites and stalagmites; the Gosthani flows through; discovered 1807 (William King George per some notes); Mesolithic paintings |
| Undavalli | Near Vijayawada, Guntur district | Rock-cut cave temples, four-storey, 4th-5th c. CE, Vishnukundins; reclining Anantasayana Vishnu; carved from a sandstone hill (some notes say granite); not karst |
| Bojjannakonda | Sankaram, Anakapalli (Visakhapatnam region) | Buddhist rock-cut caves and stupas; hilltop monastery; monolithic Buddha in Dhyana mudra (Mahayana-Vajrayana); not karst |
| Erravaram | - | Not karst (APPSC key) |
- APPSC-G1 2017: Karst topography among Bojjannakonda, Undavalli, Belum, Erravaram = Belum
- Belum: Declared a Geo-Heritage Site by GSI (Jun 2025)
- ⚠ Belum (Nandyal) and Borra (ASR) = karst; Undavalli and Bojjannakonda = rock-cut, not karst

### Coastal erosion — landforms, agents, processes, defences
## 1. Erosional coastal landforms
| Landform | Formation |
| Sea cliffs | Wave erosion |
| Wave-cut platforms | Cliff retreat |
| Sea caves | Weak zones are eroded |
| Sea arches | Caves enlarge through a headland |
| Sea stacks | Arches collapse |
| Sea stumps | Stacks are further eroded |
- Erosional sequence: Sea cliff + wave-cut platform → sea cave → arch → stack → stump
## 2. Agents, processes, causes
- Agents: Waves (main agent), tides and currents; also wind
- Processes: Hydraulic action, abrasion (corrasion), attrition, solution
- East coast erodes more: Soft, low-lying alluvial sand and silt + no rocky cliffs + flat wide plains let the sea move inland
- Human causes: Harbours, beach sand mining, offshore dredging, dams cutting sediment supply
| Defence | Methods |
| Soft | Beach nourishment, dune stabilisation, mangroves |
| Hard | Seawalls, groynes, offshore breakwaters |
### Coastal deposition → formation and meaning; coast type → example
## 1. Depositional coastal landforms
| Landform | Formation / meaning |
| Beaches | Sand or shingle accumulation; between low and high tide |
| Spits | Longshore deposition; sand ridge joined to land at one end |
| Bars | Depositional ridges across bays; bar closing a bay → lagoon (Chilika, Pulicat) |
| Lagoon | A water body separated by a bar or spit |
| Tombolo | A bar connecting an island to the mainland |
| Longshore drift | Moves the sediment; groynes built across it trap sand |
- Lagoon vs estuary: Lagoon = shallow coastal water cut off by a bar, reef or sandbar vs estuary = free connection to the sea
## 2. Coast type → example
| Coast type | Formed by | Example |
| Fiord | Drowned glacial valley | Norway |
| Ria | Drowned river valley; ranges at right angles to the shore | NW Spain |
| Dalmatian | Coast parallel to drowned ranges - mountain ranges run parallel to the coast; drowning leaves long islands + channels parallel to shore | Adriatic (Croatia) |
- ⚠ Ria = ranges at right angles; Dalmatian = ranges parallel
### Universal angles
## 1. Current relevance
- Current relevance: hanging glaciers
- Hanging glaciers: Stranded on steep slopes as the main glacier thins; collapsing → ice-rock avalanches, LLOFs and GLOFs, e.g. Nepal flash flood (1 Sep 2026)

- Geo-heritage:
- Erra Matti Dibbalu (late-Quaternary red dunes, Visakhapatnam) + Tirumala Silathoranam (quartzite arch, 1.5+ billion yr) among 7 natural sites added to UNESCO's Tentative List (Sep 2025)
- Collector ordered tourism upgrades at Erra Matti Dibbalu (15 May 2026)
## 2. AP angle
- AP angle: Coastal erosion severe at Uppada (Kakinada) and on the Krishna coast (Jul 2026)
- Lakes: Kolleru (freshwater) and Pulicat (saltwater)
# MCQ NOTES OF APP TOPIC 4:13
### Agent → landforms
## Running water
- Canyon — step-like sides, wider at top; in horizontally bedded sedimentary rocks; gorges in hard rocks
- Old (lower) course: oxbow lakes, natural levees; youth: waterfalls, potholes, rapids
- Running-water group: delta, V-valley, gorge, canyon; cirque is glacial
- Running water also: deltas, meanders, alluvial fans; peneplain — long river wearing-down
- Badlands / ravines: Chambal Valley; Chos — Hoshiarpur, Punjab
## Other agents
- Esker — glacial depositional feature; yardang, mushroom rock — aeolian
- Sand dune — heap of sand built by wind deposition
- Karst — groundwater dissolving limestone or dolomite
- Blind valley — ends suddenly where stream sinks into limestone
- Belum Caves — black limestone with stalactites and stalagmites
- Main agent of coastal erosion: waves
- Groynes — built across longshore drift to catch sand; hard defences like seawalls, breakwaters
### Glacial landforms
| Landform | Meaning |
| Arête | knife-edged ridge |
| Cirque | bowl-shaped hollow |
| Horn | sharp pyramidal peak |
| Moraine | accumulated unsorted glacial debris |
| Esker | winding ridge of stratified sediment from a sub-glacial tunnel |
| Drumlins | oval egg-shaped till hills; field gives "basket of eggs" topography |
| U-shaped valley | glacier deepens and widens a river valley |
| Hanging valley | tributary valley left high above the main valley; joins by a waterfall |

- Blind valley — a karst feature (not tectonic)
### Desert landforms
- Mushroom rock — wind-blown sand abrades the base more than the top
- Yardang — smooth ridge parallel to wind; zeugen — table-like ridge, hard cap over soft rock
- Seifs — long narrow dunes where sand is scarce; barchans — crescent, horns downwind
- Playa — evaporation of a short-lived desert lake; deflation hollow — wind removal; loess — fine silt
- Uluru — an inselberg (isolated residual hill)
- Peninsular Plateau — rejuvenated peneplain
- Beach nourishment — soft coastal defence; seawalls, groynes, offshore breakwaters are hard
### Karst depressions
- Rising size: sinkhole → doline → uvala → polje
- Polje — large closed karst hollow, often cave collapse; uvala — joined dolines; swallow hole — where a stream sinks
- Kethavaram cave paintings — Kurnool district; deer most painted; a half-painted deer also found
