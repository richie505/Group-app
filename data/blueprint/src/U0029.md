### Doctrines asked as lists — Four Noble Truths, Eightfold Path, twelve nidanas
- Four Noble Truths: Suffering; the cause of suffering; the cessation of suffering; the path
## 1. Four Noble Truths (Arya Satya)
| Noble Truth | Content |
| 1. Dukkha | Life involves suffering - life is suffering ("sabbam dukkham") |
| 2. Samudaya | Cause = craving (tanha/trishna), ignorance, attachment |
| 3. Nirodha | Cessation of suffering = Nirvana (suffering can end) |
| 4. Magga | Path to cessation = Noble Eightfold Path |
## 2. Eightfold Path (Ashtangika Marga)
- Eight steps: Right View (samma-ditthi), Intention (sankappa), Speech (vaca), Action (kammanta), Livelihood (ajiva), Effort (vayama), Mindfulness (sati), Concentration (samadhi)
| Group | Components |
| Prajna (wisdom) | Right View, Right Intention |
| Sila (conduct / ethics) | Right Speech, Right Action, Right Livelihood |
| Samadhi (mental discipline) | Right Effort, Right Mindfulness, Right Concentration |
## 3. Pratityasamutpada
- Doctrine of dependent origination: Every phenomenon arises from a cause; chain of 12 nidanas (12-link causal chain)
- Begins avidya (ignorance) → samskara (formations) → vijnana (consciousness) ... ends in old age and death
| Order | Link |
| 1-4 | Avidya (ignorance) → Samskara → Vijnana (consciousness) → Namarupa |
| 5-8 | Shadayatana (six senses) → Sparsha (contact) → Vedana (feeling) → Trishna (craving) |
| 9-12 | Upadana (clinging) → Bhava (becoming) → Jati (birth) → Jara-marana (old age-death) |
- ⚠ Samudaya = cause (craving); Nirodha = cessation; Magga = path
### Triratna and the Sangha — rules and monastic terms
## 1. The Sangha
- A monastic order — women were admitted as Bhikshunis at Vaishali; Mahaprajapati was the first woman to enter the Sangha
- Donors: Anathapindika donated Jetavana Vihara; Vishakha built Pubharama; Bimbisara built Venuvana
- Chaitya: A place of worship and prayer; Vihara: a residence of monks; Stupa: relics and burial tradition
## 2. Triratna (three jewels / refuges)
- Three pillars/refuges:
- Buddha = teacher
- Dhamma = teaching
- Sangha = order of monks and nuns, torch-bearers of Dhamma
## 3. The Sangha - rules
- Membership: Open to all above 15, regardless of caste
- Excluded: criminals, lepers, those with infectious diseases
- Women: Admitted by Buddha after requests of Ananda and Mahapajapati Gotami (Mahaprajapati Gautami)
- Monastic life:
- Vassa = rainy-season retreat of 3 months
- Vinaya: Monastic code
- Bhikkhuni Sangha taken to Sri Lanka by Sanghamitta; thrived 1,000+ years until the Chola invasion of 1017 AD
## 4. Ascetic and Sangha terms
| Term | Meaning |
| Bhikkhu / Bhikkhuni | Monk / nun living on alms |
| Pravrajya | Going forth - leaving lay life (head-shaving, robes) |
| Upasampada | Full ordination |
| Uposatha | Fortnightly (full/new moon) confession and rule-recitation |
- ⚠ Pravrajya = going forth; Upasampada = full ordination; Uposatha = fortnightly confession
