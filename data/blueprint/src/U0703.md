# NOTES OF APP TOPIC 5:13 - Networks and the internet - LAN/WAN, protocols, IP, DNS, web technologies
### Internet firsts
- The internet is a global WAN; DNS is its directory (name → IP address)
- 1969 — ARPANET, US Department of Defense
- 1986 — ERNET: academic network (India)
- 1989 — WWW: Tim Berners-Lee, CERN
- 1995 — VSNL public internet, 15 August
- 1998 — Sify: first private ISP; ICANN set up
- 2003 — NIXI (MeitY): .in registry, IRINN
### Network types & topologies
| Type | Scope / layout |
| PAN / LAN / MAN | Bluetooth / campus / city |
| WAN | Links LANs; internet = global WAN |
| VPN | Encrypted tunnel over public network |
| Star | Central hub; hub failure stops all |
| Mesh | Most resilient; n(n-1)/2 links |

### Network types and topologies → scope and resilience
| Type | Scope |
| PAN | Personal area (Bluetooth) |
| MAN | A city |
| WAN | Spans large areas, links LANs → the internet is a global WAN |
| VPN | Encrypted "tunnel" over a public network |
- Firm linking LANs in Mumbai, Bengaluru and New Delhi uses a WAN (APPSC 2019)
| Topology | Layout | Resilience |
| Bus | All nodes on one backbone cable | Backbone break stops the whole network [GK] |
| Star | All nodes to a central hub/switch | One node failing is isolated; hub failure stops all [GK] |
| Ring | Each node linked to two neighbours | One break can disrupt the ring [GK] |
| Mesh | Every node linked to every other | Most resilient; costliest (n(n-1)/2 links) [GK] |
### OSI model and network devices → layer
| Layer (top to bottom) | Protocols / devices |

### Protocols → function
| Protocol | Function |
| TCP/IP | Basic suite of the internet: TCP ensures reliable delivery, IP addresses and routes packets |
| HTTP / HTTPS | Transfers webpages - HTTP sets how messages pass between browsers and web servers; HTTPS encrypts browser-server traffic (via TLS) |
| FTP | File transfer between computers [GK] |
| SMTP | Sends e-mail [GK] |
| POP3 | Downloads mail to one device, usually deletes it from the server [GK] |
| IMAP | Keeps mail on the server, synced across devices [GK] |
| DNS (Domain Name System) | Internet's directory - turns human-readable names into numerical IP addresses (name → IP address) |
| DHCP | Assigns IP addresses automatically [GK] |
- ⚠ SMTP sends; POP3 downloads and deletes; IMAP keeps on server
- Three elements of a protocol:
- Syntax: format of data
- Semantics: meaning of each field
- Timing: when and how fast to send

### Web terms → meaning
| Term | What it does |
| Web server | Keeps information in webpages marked up with HTML tags (HTML = HyperText Markup Language); stores webpages and sends (serves) them on request |
| Web browser | Requests (fetches) webpages and displays them on screen (Chrome, Firefox) [GK] |
| Search engine | Indexes webpages so they can be found (Google, Bing) |
| URL | Uniform Resource Locator; parts: protocol (`https://`) + domain name (`www.example.in`) + path to the file |
| Web 3.0 | Third generation of the web - changes how the web is used, how sites are managed, how services are delivered |
| OCEN (Open Credit Enablement Network) | Linked standard; aims to democratise lending so small borrowers get the best credit terms |
- Exam angle: "which one displays webpages" (browser) vs "which one stores them" (server).
- W3C (World Wide Web Consortium): Develops and maintains web standards so pages work the same across browsers
- Core front-end technologies: HTML5, CSS3, JavaScript
| Layer of the web | Share | Features |
| Surface (clear) web | ~4-5% | Indexed by search engines |
| Deep web | ~90-95% | Not indexed: e-mail inboxes, net banking, intranets; not malicious as such |
| Dark web | Small hidden subset of the deep web | Needs Tor / I2P; anonymous; linked with illegal markets |

### OSI model and network devices → layer
## Modem
- ★ Modem (Modulator/Demodulator) — does modulation and demodulation
- converts digital to analog and analog to digital (both)
- links a microcomputer with the telephone; sends and gets data between computers worldwide over telephone lines
## Other devices and layers
- ★ Repeater — extends a network by amplifying the signal along the cable
- ★ Proxy server — middleman passing client requests to other servers; does not provide TCP/IP addresses
- ★ IP addresses — used on the Network layer (Layer 3; the Internet layer of TCP/IP), where routing lives
- ★ Data Link layer — between the Physical and Network layers (OSI ratified 1984)
- ★ Protocol — a set of rules that controls data communication
### Transmission modes, connections and wireless standards
- ★ Podcast — a radio programme shared via the internet
- ★ DSL (Digital Subscriber Line) — internet connection over telephone lines (voice frequency)
- ★ Dial-up — slowest internet connection, up to 56 Kbps; cable modem uses coaxial lines of cable companies
### Protocols → function
