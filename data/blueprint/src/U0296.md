- Order — each preceded the next: A.K. Gopalan → Shankari Prasad → Champakam Dorairajan → Berubari Union → Sajjan Singh → Golaknath → Kesavananda Bharati → Indira Gandhi v. Raj Narain → Maneka Gandhi → Minerva Mills → Kihoto Hollohan → S.R. Bommai
