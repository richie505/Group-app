### Industrial revolutions — stages, definitions and FIRSTs
## 1. Stages 1.0 to 5.0
| Stage | Defining technology |
| Industry 1.0 | Mechanisation, steam power, weaving loom |
| Industry 2.0 | Electricity, mass production, assembly line |

### Terms → meaning (automation, IoT, manufacturing, extended reality)
| Term | Meaning |
| PLC | Programmable Logic Controller, a rugged industrial computer controlling machines [GK] |
| SCADA | Supervisory Control and Data Acquisition, remote monitoring of plants and grids [GK] |
| Digital twin | Virtual replica of a physical object/system for simulation and monitoring |
| Cyber-physical system | Computing tightly integrated with physical processes; core of Industry 4.0; NM-ICPS mission |
| IoT = Internet of Things (APPSC 2023, 2024) | Devices with sensors, linked in a network, exchanging data without human intervention |
| RFID | Radio waves between a tag (carries identity data) and a reader |
| mMTC | Massive machine-type communication; the 5G slice that serves dense IoT sensors |
| Cobots | Collaborative robots working safely alongside humans; spreading in Indian factories |
| Swarms | Many drones coordinated by software → surveillance, light shows or strikes |
| Additive manufacturing | Builds an object layer by layer from a digital (CAD) model; opposite of subtractive machining |
| 4D printing | Adds materials that change shape over time |
| Virtual Reality (VR) | Fully computer-generated, immersive world; the user is still a real person (APPSC 2024) |
| Augmented Reality (AR) | Digital layers over the real world (e.g. Pokemon Go) [GK] |
| Mixed Reality (MR) | Real and virtual objects interact in real time [GK] |
| Extended Reality (XR) | Umbrella term for VR + AR + MR [GK] |
| Metaverse | Persistent, shared 3D virtual space using XR, avatars, digital assets [GK] |
- ⚠ XR = umbrella for VR + AR + MR; in VR the user is still a real person
- ⚠ 3D printing = additive (layer by layer), not subtractive; 4D = shape changes over time
### IoT — layers, variants, IoT vs AI and RFID tags
## 1. Layers and variants
- Three-layer model:
- Application: smart services
- Variants: IIoT (industrial automation), IoNT (nano-devices), Internet of Mobile Things, mission-critical IoT (military)
## 2. IoT vs AI
| IoT | AI |
| Collects and exchanges data through sensors | Analyses data, recognises patterns, decides |
| Smart thermostat, fitness wearable | Chatbot, image recognition |
## 3. RFID tags - passive vs active
| Tag | Power | How it responds |
| Passive | No internal battery; powered by the reader's field [GK] | Reflects/backscatters the signal; cheap, short range [GK] |
| Semi-passive | Battery runs the chip only [GK] | Still uses the reader's field to reply [GK] |
| Active | Own battery and transmitter [GK] | Broadcasts itself; long range [GK] |
- ⚠ Trap: "passive tags are powered by an internal circuit" is wrong (APPSC-G1 2022 key: II and IV only)
