### Malnutrition → terms and meaning
| Indicator | Measure |
| Stunting | Low height-for-age (chronic undernutrition) |
| Wasting | Low weight-for-height (acute undernutrition) |
| Underweight | Low weight-for-age |
| Term | Meaning |
| Undernutrition | Protein-energy malnutrition + micronutrient deficiency + stunting + wasting (+ underweight) (APPSC-GS 2019; WHO) |
| Overnutrition | Overweight and obesity |
| Double burden of malnutrition | Undernutrition + overnutrition in the same population; NFHS-6 confirms India faces it (5 Jun 2026) |
- ⚠ Stunting = height-for-age (chronic); wasting = weight-for-height (acute); underweight = weight-for-age
