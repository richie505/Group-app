### Remote sensing — definitions, types and what it measures
## 1. Definition and types
- Remote sensing: Information about Earth's surface without physical contact, from reflected/emitted radiation
| Basis | Types |
| Source of energy | Passive (solar radiation - Resourcesat, Oceansat) vs active (own signal - RISAT radar) |
- ⚠ Active = own signal (RISAT); passive = sunlight (Resourcesat, Oceansat)
## 2. Microwave / SAR and InSAR
- Microwave/SAR: Microwave (radar/SAR) bands see through cloud and darkness - used for cloud-covered areas
- E.g., Assam's planned flood satellites may carry SAR (State cloudy half the year) (25 Mar 2026)
- InSAR: (Interferometric SAR) compares phase of two or more radar images of the same place to map ground deformation
- Uses: earthquakes, land subsidence, landslides, volcanoes, glacier movement
- NISAR detects ground movement to the centimetre - land subsidence, earthquakes, glaciers
## 3. What can be measured
- Land cover, vegetation, chlorophyll, forest cover, surface and groundwater prospects
- Snow and glaciers, soil, wetlands, mineral/hydrocarbon zones
- Crop area and yield (YES-TECH)
### Terms → meaning: spectral indices and GIS
## 1. Spectral indices
| Term | Meaning |
| NDVI | Normalized Difference Vegetation Index = (NIR - Red) / (NIR + Red); basis: healthy vegetation reflects strongly in NIR; range -1 to +1; high values = healthy green vegetation |
| Vegetation Condition Index (VCI) | Derived from NDVI; used for drought declaration (2024-25) - mandal-level in AP |
| NH Green Cover Index 2025-26 | (NHAI + NRSC) India's first satellite-based green-cover assessment of highways; uses chlorophyll detection over about 30,000 km in 24 States |
- NDVI: Most widely used index for operational drought assessment (PYQ)
## 2. GIS components
| Component | Examples [GK] |
| Hardware | Computer, digitizer, scanner, GPS receiver, plotter |
| Software | GIS packages (e.g., QGIS - used in APSAC workshops) |
| Data | Spatial (vector: points, lines, polygons; raster: satellite images) + attribute tables |
- Data layers: Each theme (roads, soils, land use, water) = a layer; overlay analysis combines them
- Situational awareness: Real-time layers for disaster response, flood alerts, shoreline mapping

### Remote sensing tools
## Sensing types
- Active sensing — sends its own signal, e.g. RISAT radar; passive — natural radiation, e.g. Resourcesat, Oceansat
- SAR / microwave — sees through cloud cover and in darkness, so flood mapping; RISAT (SAR) maps floods through clouds
- InSAR — compares the phase of two or more radar images of the same area → ground deformation
- Soil moisture — best measured by microwave / SAR sensors; NISAR uses L-band and S-band radar
## Indices
- NDVI = (NIR − Red) / (NIR + Red); healthy vegetation reflects strongly in near-infrared
- NDVI — most widely used index for operational drought assessment
- NH Green Cover Index 2025-26 — India's first satellite-based green-cover assessment of national highways; chlorophyll detection
