### Remote sensing — definition, components, sensor types
- Definition: Information about the Earth without physical contact, from reflected or emitted electromagnetic radiation
- Components of a remote sensing system:
- Energy source/illumination → radiation through the atmosphere → interaction with target → recording by sensor → transmission, reception and processing → interpretation → application
- ⚠ Trap: "Interaction of energy with minimization/minimisation" is NOT a component (APPSC 2022)
| Sensor type | Energy source | Examples |
| Passive | Natural sunlight (Sun's reflected light) or the target's emitted heat | IRS, Resourcesat, Oceansat, cameras (visible cameras), multispectral/hyperspectral imagers, infrared radiometers |
| Active | Own signal: sensor sends its own pulse and reads the echo | RISAT radar (SAR), laser/LiDAR (APPSC 2023: laser is active) |
| Imaging type | Feature |  |
| Optical (visible/NIR) | Reflected light → needs daylight + clear sky; blocked by cloud |  |
| SAR (microwave) | Pierces clouds and darkness → sees at night |  |
| Hyperspectral | Hundreds of narrow bands → material/chemical identification (EOS-N1) |  |
### Resolution types and remote-sensing techniques → what they map
- Four resolution types: spatial, spectral, temporal, radiometric
- ⚠ Trap: "chemical" resolution does not exist (APPSC 2025)
| Technique | Maps |
| InSAR | Ground deformation - subsidence, earthquake and volcano uplift [GK] |
| LiDAR | Laser ranging - elevation, 3D terrain, forest canopy height [GK] |
| NDVI | Vegetation health from red vs near-infrared reflectance [GK] |
| Thermal infrared | Records emitted heat - volcanic eruptions (APPSC 2023: infrared-sensitive sensors), forest fires, urban heat |
### Orbits for Earth observation → altitude and use
- LEO = Low Earth Orbit: Most EO satellites fly in sun-synchronous polar orbits
- SSO features:
- Near-polar; passes each place at same local solar time → consistent lighting
- Trade-off:
- LEO = fine detail but periodic revisit
- Geosynchronous imagers (EOS-05, ~36,000 km) = coarser detail but priority targets every 5 min + all of India every 30 min (4 Sep 2026; 7 Sep 2026)
| Orbit | Altitude | Key use |
| LEO | 200-2,000 km | Earth observation, ISS, Starlink-type constellations |
| MEO | 2,000-30,000 km | Navigation (GPS) |
| GEO (geostationary) | 35,786 km over the Equator | Communication, weather; satellite appears fixed |
| GSO (geosynchronous) | Same altitude, inclined/elliptical | Traces a figure-8; NavIC's 4 inclined satellites |
| SSPO (sun-synchronous polar) | Polar, ~500-900 km | Passes the same place at the same local time daily, giving uniform lighting for imaging |
- GEO vs GSO: Both have period of one sidereal day, about 23 h 56 min
- Geostationary = special case with zero inclination + circular orbit

### Remote sensing basics
## Basics
- ★ Remote sensing uses electromagnetic waves (part of the EM spectrum)
