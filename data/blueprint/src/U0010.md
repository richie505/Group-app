| Shape | Feature |

## 2. Uses and value as a source
- Functions: Trade regulation + long-distance communication
- Exam angle: long-distance communication → "seals and sealings" (APPSC-G1 2017); distinctive feature of IVC → seals (APPSC-GS 2024).
### Weights — material, shape, binary-decimal system
- Material: Mostly chert; also limestone and steatite
- Shape: Cubical
| Denomination | System |
| Lower | binary (1:2:4:8:16:32:64) |
| Higher | decimal multiples (160, 320, 640, 1600, 3200) |
- ⚠ Lower = binary; higher = decimal
- Uniformity: Same weights across about 8,00,000 sq km → central regulation
- Finds: Ivory weight balance at Mohenjodaro and Lothal; chert trade weights at Rakhigarhi
### Harappan script — features, numbers and FIRSTs
## 1. Nature and direction
| Feature | Fact |
| Nature | Mostly pictographic + some abstract signs |
| Direction | Right to left (cramped spacing at the left end) |
## 2. Numbers
| Item | Number |
| Number of signs | About 400; estimates range 400-700 |
| Inscription length | Average about 5 signs |
| Longest known inscription | 26 signs |
| Corpus | About 5,000 inscribed objects |
| Dholavira signboard | 10 large signs - the famous 10-sign inscription |
- Found on: Seals, tablets, pottery, copper plates, tools
- ⚠ Average 5 signs; longest 26; signboard 10; total signs about 400
## 3. FIRSTs
- FIRST/LAST: Indus script = among the world's earliest writing systems
## 4. Dholavira
- Excavated by R.S. Bisht, 1990
- Only Harappan site on the UNESCO World Heritage list (2021)
### Scholars → decipherment hypotheses
- Status: No bilingual text → still undeciphered
| Hypothesis | Scholar | Standing |
| Proto-Dravidian | Iravatham Mahadevan, Asko Parpola | Most widely supported |
| Indo-Aryan (early Sanskrit) | S.R. Rao | Minority view; Rig Veda post-dates Mature Harappan |
- ⚠ Mahadevan, Parpola = Proto-Dravidian; S.R. Rao = Indo-Aryan
- Criticism & debates: Language of the script (Dravidian vs Indo-Aryan) remains open
### Universal angles
- Significance: Uniform seals + weights = main proof of standardisation and regulated trade
- Current relevance (Jun 2026): Rakhigarhi - cylindrical steatite seal with alligator motif + five Harappan characters; chert trade weights
