=== ROW 131 | Central assistance to Andhra Pradesh - Finance Commission transfers and centrally sponsored schemes

## Central assistance terms → meaning — Gadgil formula, CS vs CSS, SNA-SPARSH | from: S0, S2
# 1. Gadgil formula (Plan era, historical)
- **Plan-era funding:** State's own resources + **Normal Central Assistance** via **Gadgil (Gadgil-Mukherjee) formula**
  - Loans:grants = **70:30** for general category States
  - **10:90** for special category States
- **State Plan grants:** (~3% of divisible pool) discontinued
- **Plan/non-Plan distinction:** Dropped from the 2017-18 Budget
- !! Not in your sources: AP-specific share of central assistance in historical Plan outlays.
- ⚠ Gadgil loans:grants **70:30** (general) vs CSS sharing **60:40** — different ratios
# 2. CS vs CSS
- **Definition:** CSS = Centre-designed schemes on State subjects needing a **matching State share**

| **Central Sector (CS)** | **Centrally Sponsored (CSS)** |
|---|---|
| Union List subjects | State/Concurrent subjects |
| **100%** Centre-funded, run by Central Ministry | Shared **60:40** for general States (**90:10** special category/NE/Himalayan States) |
| PM-KISAN, Ayushman Bharat, MPLADS | NHM, PMAY, ICDS, PMKSY |
| 17% of Union spending (Budget 2026-27) | 8% of Union spending |

- **MGNREGA shift:** **100% Central** for unskilled wages → replaced by **VB-G RAM G Act** (**60:40** for most States)
  - Impact: raises State contributions
- **Appraisal cycle:** New 5-year CSS/CS cycle from **1 Apr 2026**, aligned with 16th FC; 16th FC wants CSS tied to measurable outcomes
- ⚠ PM-KISAN / Ayushman Bharat = **CS**; NHM / PMAY = **CSS**
# 3. SNA-SPARSH
- **Mechanism:** "Just-in-time" release of CSS funds from Centre & State Consolidated Funds via **State IFMIS, RBI e-Kuber and PFMS**
- **Coverage:** All **28 States and 3 UTs**; **66 notified CSS**
- **Benefit:** Cuts reliance on WMAs
- **Impact:** "Credit-push" → "debit-pull" cut idle float **Rs. 1.67 lakh Cr → Rs. 0.4 lakh Cr** (ES 2025-26)
