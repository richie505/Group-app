## Phase 1 & 2 (owner's rules, verbatim in substance)
For EVERY PYQ (src not app/ca/rocket) in rows 46-49:
1. Correct key: analyse the PYQ against the notes. Notes clearly support one option → that is the key.
2. "From the Notes": use only information already in the notes' explanation text (same content, same framing) —
   quote the notes' own sentence(s); do not invent text when the notes cover it.
3. Conflict with the notes / ambiguous / outdated → Generation Method: web search for the current, relevant fact,
   regenerate key + explanation from notes + verified fact; never just copy an existing key when in doubt.
4. Outdated PYQs: tag "⚠ Outdated: … — now … (source)" + inline "(now …)", with the current fact.
5. Existing explanation contradicts the key → Generation Method.
6. Generation Method ONLY for conflict / ambiguity / outdated / contradiction; all others resolved from the notes.
7. Cite the source (Drive file name or URL) for every key. Every PYQ ends with a key; no explanation contradicts it.
   (A key that the notes and the official APPSC key both settle follows them; a disputed official key is noted with ⚠.)
