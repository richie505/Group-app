=== NOTES 5:13 | Networks and the Internet – Lan/wan, Protocols, Ip, Dns, Web Technologies
## SUB 0 | Internet – Basics and History
[13:0:0] - The **Internet** is "a **network of networks**", connected by **TCP/IP**; it is a global **WAN**.
[13:0:1] - **DNS** is the internet's directory: it turns **domain names into IP addresses**.
[13:0:2] # Internet Firsts – Timeline
[13:0:3] TABLE head: Year | Event
  [13:0:3.0] 1969 | ARPANET, built under the US Department of Defense – forerunner of the internet
  [13:0:3.1] 1984 | OSI model ratified
  [13:0:3.2] 1986 | ERNET – academic network of India
  [13:0:3.3] 1989 | WWW invented by Tim Berners-Lee at CERN
  [13:0:3.4] 1994 | W3C founded by Tim Berners-Lee
  [13:0:3.5] 1995 | VSNL launched public internet in India on 15 August 1995
  [13:0:3.6] 1998 | Satyam Infoway (Sify) – first private ISP of India; ICANN set up
  [13:0:3.7] 2003 | NIXI set up under MeitY
  [13:0:3.8] 2022 | BhashaNet launched (MeitY-NIXI)
  [13:0:3.9] 2023 | Telecommunications Act replaced the Indian Telegraph Act, 1885
[13:0:4] # World Wide Web
[13:0:5] - **WWW (W3)** = **World Wide Web**: information system for sharing content over the internet, accessed according to **HTTP**.
[13:0:6] - A collection of linked information on computers available through the internet.
[13:0:7] - WWW is a **hypermedia system** because it links to other computer resources (linked hypertext documents).
[13:0:8] Internet (network of networks) and WWW (information system on top of it) are not the same thing.
## SUB 1 | Network Types and Topologies
[13:1:0] # Network Types by Scope
[13:1:1] TABLE head: Type | Scope / feature
  [13:1:1.0] PAN | Personal area; personal devices (Bluetooth)
  [13:1:1.1] LAN | A building or campus; Ethernet is an example (protocol IEEE 802.3)
  [13:1:1.2] MAN | A city
  [13:1:1.3] WAN | Spans large areas and links LANs in different cities; the internet is a global WAN
  [13:1:1.4] VPN | Virtual Private Network – an encrypted tunnel over the public internet letting users reach their organisation's network safely; improves privacy
[13:1:2] APPSC 2019: A firm linking LANs in **Mumbai, Bengaluru and New Delhi** uses a **WAN**.
[13:1:3] # Topologies
[13:1:4] TABLE head: Topology | Layout | Resilience
  [13:1:4.0] Bus | All nodes on one backbone cable | Backbone break stops the whole network
  [13:1:4.1] Star | All nodes to a central hub/switch | A failed node is only isolated; hub failure stops all
  [13:1:4.2] Ring | Each node linked to two neighbours | One break can disrupt the ring
  [13:1:4.3] Mesh | Every node linked to every other | Most resilient; costliest – n(n-1)/2 links
  [13:1:4.4] Tree | Mix of bus and star | Used by the Internet
  [13:1:4.5] Hybrid | Mix of types | The Internet is the largest hybrid topology
[13:1:5] - Common topologies: star, bus, ring, tree, mesh, hybrid.
[13:1:6] "Which is NOT a common topology?" – **Grid**.
## SUB 2 | Osi Model and Network Devices
[13:2:0] # Seven Layers (top to bottom)
[13:2:1] TABLE head: Layer | Function | Protocols / devices
  [13:2:1.0] 7 Application | User services | HTTP, FTP, SMTP, DNS
  [13:2:1.1] 6 Presentation | Encryption, compression, formats (JPEG) | –
  [13:2:1.2] 5 Session | Opens and closes sessions | –
  [13:2:1.3] 4 Transport | End-to-end delivery | TCP, UDP
  [13:2:1.4] 3 Network | Routing; IP addresses (Internet layer of TCP/IP) | Router
  [13:2:1.5] 2 Data Link | Framing, MAC addresses, error detection; Ethernet, PPP | Switch, bridge, NIC
  [13:2:1.6] 1 Physical | Signals on the medium | Cables, hub, repeater, modem
[13:2:2] - The **Data Link layer** lies between the Physical and Network layers.
[13:2:3] # Devices
[13:2:4] TABLE head: Device | Job
  [13:2:4.0] Hub | Broadcasts to all ports
  [13:2:4.1] Repeater | Regenerates/amplifies a weak signal to extend the network along the cable
  [13:2:4.2] Switch / Bridge | Forwards frames by MAC address
  [13:2:4.3] Router | Connects different networks; routes by IP
  [13:2:4.4] Modem | Modulator-demodulator: converts digital → analog and analog → digital (both); links a microcomputer with the telephone line to send and get data worldwide
  [13:2:4.5] Gateway | Joins networks that use different protocols
  [13:2:4.6] Proxy server | Middleman passing client requests to other servers; does not provide TCP/IP addresses
  [13:2:4.7] Network server | Powerful central store for shared data and programs
[13:2:5] The modem is **not** a Transport-layer device; it works at the Physical layer.
## SUB 3 | Protocols
[13:3:0] - A **protocol** is a **set of rules that controls data communication**.
[13:3:1] # Protocol → Function
[13:3:2] TABLE head: Protocol | Function
  [13:3:2.0] TCP/IP | Set of protocols for all data exchange across the internet; TCP makes packets and checks none is missing (reliable delivery); IP addresses and routes packets
  [13:3:2.1] HTTP | Hypertext Transfer Protocol – used for accessing the WWW; sets how messages pass between browsers and web servers
  [13:3:2.2] HTTPS | Safer than HTTP – encrypts browser-server traffic via TLS
  [13:3:2.3] FTP | File Transfer Protocol – sharing files over the internet
  [13:3:2.4] SMTP | Sends e-mail
  [13:3:2.5] POP3 | Downloads mail to one device, usually deletes it from the server
  [13:3:2.6] IMAP | Keeps mail on the server, synced across devices
  [13:3:2.7] DNS | Domain Name System – list of names and addresses of internet hosts; name → IP address
  [13:3:2.8] DHCP | Assigns IP addresses automatically
[13:3:3] # Three Elements of a Protocol
[13:3:4] TABLE head: Element | Meaning
  [13:3:4.0] Syntax | Format of data
  [13:3:4.1] Semantics | Meaning of each field
  [13:3:4.2] Timing | When and how fast data is sent
## SUB 4 | Ip and Mac Addressing
[13:4:0] TABLE head: Address | Length | Notation
  [13:4:0.0] IPv4 | 32 bits (~4.3 billion addresses) | Dotted decimal, e.g. 192.168.1.1
  [13:4:0.1] IPv6 | 128 bits | 8 groups of hexadecimal separated by colons
  [13:4:0.2] MAC (Media Access Control) | 48 bits (6 bytes, 12 hex digits) | Unique device identifier programmed into the NIC; used at the data link layer (Layer 2)
[13:4:1] - IPv4 and IPv6 addresses identify computers on the internet.
[13:4:2] # IPv4 Classes (by first octet)
[13:4:3] TABLE head: Class | Range | Use
  [13:4:3.0] A | 1–126 | Large networks
  [13:4:3.1] B | 128–191 | Medium networks
  [13:4:3.2] C | 192–223 | Small networks
  [13:4:3.3] D | 224–239 | Multicast
  [13:4:3.4] E | 240–255 | Experimental
## SUB 5 | Transmission Modes and Connections
[13:5:0] TABLE head: Mode | Meaning | Example
  [13:5:0.0] Simplex | One way | Radio/TV broadcast, keyboard
  [13:5:0.1] Half duplex | Both ways, one at a time | Walkie-talkie
  [13:5:0.2] Full duplex | Both ways at once | Telephone call
  [13:5:0.3] Connection | Medium
  [13:5:0.4] DSL (Digital Subscriber Line) | Telephone copper lines (voice frequency)
  [13:5:0.5] Cable internet | Coaxial lines of cable TV companies (cable modem)
  [13:5:0.6] Fibre | Light pulses in optical fibre
  [13:5:0.7] Dial-up | Slowest – up to 56 Kbps
  [13:5:0.8] Satellite internet | Space, ground and user (VSAT) segments; needs no terrestrial wire
[13:5:1] - "G" in **2G** stands for **Generation** (2nd Generation wireless technology).
[13:5:2] - A **podcast** is a radio programme shared via the internet.
## SUB 6 | Wireless Standards
[13:6:0] TABLE head: Feature | Bluetooth | Wi-Fi
  [13:6:0.0] Standard | IEEE 802.15.1 (PAN technology) | IEEE 802.11 (wireless LAN)
  [13:6:0.1] Band | 2.4 GHz | 2.4 and 5 GHz (Wi-Fi 7 also 6 GHz)
  [13:6:0.2] Range | Short (~10 m, class 2) | Longer, whole building
[13:6:1] - **APPSC 2019 key**: latest Bluetooth version = **5.1** (follow the key for that question).
[13:6:2] - Since then: **Bluetooth 6.0** (August 2024) added **Channel Sounding**; **6.1** and **6.2** followed in 2025 under a twice-yearly schedule.
[13:6:3] - **Wi-Fi 7** = **IEEE 802.11be**; works in **2.4, 5 and 6 GHz** bands.
[13:6:4] - **Wi-Fi Direct**: links devices with no LAN.
[13:6:5] - **Li-Fi**: carries data on **LED light**; better bandwidth and security than Wi-Fi.
## SUB 7 | Web Technologies
[13:7:0] # Web Terms
[13:7:1] TABLE head: Term | Meaning
  [13:7:1.0] Web server | Stores webpages (marked up with HTML tags – HyperText Markup Language) and serves them on request
  [13:7:1.1] Web browser | Requests and displays webpages (Chrome, Firefox)
  [13:7:1.2] Search engine | Indexes webpages so they can be found (Google, Bing)
  [13:7:1.3] Web crawler | Also a web spider (spiderbot); internet bot that scans the Web for indexing
  [13:7:1.4] Home page | First page a browser shows on opening a website
  [13:7:1.5] URL | Uniform Resource Locator; order: protocol (`https://`) → domain name (`www.example.in`) → path to the file
  [13:7:1.6] E-mail address | user name + domain name (username@domainname.extension)
  [13:7:1.7] .edu.us | An educational institute in the USA (.us = United States, .edu = education)
  [13:7:1.8] Web 3.0 | Third generation of the web – changes how the web is used, how sites are managed and how services are delivered
  [13:7:1.9] JSP | Java Server Pages – web pages made live; released 1999 by Sun Microsystems
  [13:7:1.10] OCEN | Open Credit Enablement Network – aims to democratise lending so small borrowers get the best credit terms
[13:7:2] - **W3C** (World Wide Web Consortium): main international **web standards body**; founded **1994** by **Tim Berners-Lee**; keeps pages working the same across browsers.
[13:7:3] - Core front-end technologies: **HTML5, CSS3, JavaScript**.

  [13:7:5.0] Yahoo | Search engine, not a web browser

  [13:7:5.5] Internet Explorer (now Microsoft Edge), Firefox, Opera, Vivaldi | Web browsers
  [13:7:5.6] Google Apps | Not a web browser
  [13:7:5.7] Orkut | Closed social networking site, not a search engine
[13:7:6] # Layers of the Web
[13:7:7] TABLE head: Layer | Share | Features
  [13:7:7.0] Surface (clear) web | ~4-5% | Indexed by search engines
  [13:7:7.1] Deep web | ~90-95% | Not indexed – e-mail inboxes, net banking, intranets; not always harmful
  [13:7:7.2] Dark web | Small hidden part of the deep web | Needs Tor / I2P; anonymous; linked with illegal markets
## SUB 8 | Internet Governance and India
[13:8:0] TABLE head: Body / Act | Year | Role
  [13:8:0.0] ICANN | 1998 | US non-profit; manages the global Domain Name System and IP address allocation
  [13:8:0.1] NIXI (National Internet Exchange of India) | 2003 | Not-for-profit under MeitY; runs internet exchange points, the .in registry and IRINN (IP addresses)
  [13:8:0.2] BhashaNet | 2022 | MeitY and NIXI (not ICANN) – Universal Acceptance for Indian languages; .Bharat in Devanagari
  [13:8:0.3] IT Act, 2000 | 2000 | Sections 69A and 79 – government can order ISPs and intermediaries to block content
  [13:8:0.4] Telecommunications Act, 2023 | 2023 | Replaced the Indian Telegraph Act, 1885; holds the power to suspend internet services
[13:8:1] - **Universal Acceptance**: every app and e-mail system accepts all domain names and e-mail IDs, including those in Indian scripts (internationalised domain names).
[13:8:2] - **7 Apr 2026**: a site opening on one ISP but not another is due to ISP-level **DNS poisoning, HTTP interception or SNI filtering** (on HTTPS); blocklists differ across ISPs.
[13:8:3] - **Economic Survey 2025-26**: internet connections rose from **25.15 crore (2014)** to **96.96 crore (2024)**; **BharatNet** fibre reaches **2.18 lakh gram panchayats**.
[13:8:4] - **AP angle (29 Jun 2026)**: CM **Chandrababu Naidu** and **Sunil Mittal** discussed **last-mile connectivity, data centres and an undersea cable landing station** for Andhra Pradesh.
