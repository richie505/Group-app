=== Statistics – Averages, Dispersion, Probability and Distributions
# Central tendency
- **Mean, median and mode** = **measures of central tendency** (averages).
- **Mode** = most frequent value – **located by inspection** and easily understood by common people.
- **Median** = the value that **divides an ordered series into two equal parts**.
- **Empirical relation (moderately skewed data, Karl Pearson):** **Mode = 3 Median − 2 Mean** ⇔ **Mean − Mode = 3 (Mean − Median)** ⇔ **Mode − Mean = 3 (Median − Mean)**.
- For positive values (not all equal): **AM > GM > HM** (equal only when all values are equal).
# Dispersion
- **Standard deviation** = positive **square root of the variance**; for homogeneous data (all values equal) **SD = 0**.
- **Histogram** = adjacent bars showing frequencies of values within **consecutive, fixed class intervals**.
# Probability and distributions
- **Independent events:** P(both miss) = (1 − 0.6) × (1 − 0.8) = **0.08**; an **impossible event** (six girls from a class with only five) has probability **zero**.
- If the population is **normal**, the sampling distribution drawn from it is also **normal**.
- **Chi-square distribution:** **asymmetric – positively (right) skewed**, nearly symmetric only for large degrees of freedom; used for **goodness-of-fit** tests (does a population follow a given theoretical distribution?).

=== Statistics – Sampling, Hypothesis Testing, Correlation and Regression
# Sampling
| Term | Meaning |
|---|---|
| Population / universe | The whole group from which sample units are drawn |
| Simple random sampling | **Every unit has an equal chance** of selection; suits a **homogeneous** population |
| Stratified sampling | A **heterogeneous** population is divided into homogeneous **strata (classes)** and a sample is drawn from each |
| Sampling distribution | Distribution of a **sample statistic** over all possible samples |
# Hypothesis testing
- **Hypothesis** = an assumption or proposition whose validity is to be tested.
- **Type I error** = rejecting a true hypothesis; **Type II error** = **accepting a false hypothesis**.
# Correlation and regression
- **Correlation coefficient (Karl Pearson's r)** lies between **−1 and +1**.
- **Multiple regression** has one intercept and **more than one partial regression coefficient**.
| Term | Meaning |
|---|---|
| Multicollinearity | Significant correlation **between the independent variables** |
| Autocorrelation | Correlation of errors over time – detected by the **Durbin-Watson (DW) statistic** |
| Adjusted R² | R² adjusted for **degrees of freedom** |
| ARIMA | **Auto Regressive Integrated Moving Average** – time-series forecasting model |
