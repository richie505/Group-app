[27:0:2] - Latest: AP now offers services on **WhatsApp** (Mana Mitra, 2025) and is building AI-based governance under RTGS.

## SUB 1 | Meeseva

[27:1:2] - **Single-window G2C** delivery; **succeeded e-Seva**; launched **2011** in the combined state.
[27:1:3] - Delivery channels: **MeeSeva franchise centres** + **online portal**; also enrolment for Aarogya Raksha.

## SUB 2 | E-pragati – Ap State Enterprise Architecture
[27:2:0] - **e-Pragati** = new name of the **AP State Enterprise Architecture (APSEA)**; approved by the state cabinet in **2015**.
[27:2:1] - Outlay **Rs 2,358 crore**: **72 projects** in **14 packages**, over three years; state share about Rs 1,528 crore, rest via **PPP**.
[27:2:2] - Covers **33 secretariat departments** and **300+ government agencies**; built with **Wipro**.
[27:2:3] - Aim: all government services under one roof through a single architecture ("Digital AP").
## SUB 3 | Rtgs – Real Time Governance Society
[27:3:0] # Set-up
[27:3:1] - **Real Time Governance Society (RTGS)** formed on **6 September 2017**; works directly under the **Chief Minister**.
[27:3:2] - **RTG State Centre** (command centre) inaugurated at the **Secretariat, Velagapudi** on **26 November 2017**.
[27:3:3] - Dashboards pull data from surveillance cameras, drones, biometric systems and **AWARE** (AP Weather Forecasting and Early Warning Research Centre).
[27:3:4] - Revived from 2024 as an **AI-driven** governance platform.
[27:3:5] - **Swarna Andhra @2047** pillar: **"Effective Governance and AI-based Public Services"**; monitoring tracks KPIs; OBD/IVRS calls and bulk WhatsApp for citizen feedback.
[27:3:6] - AP has **59 Chief Data Officers**.
[27:3:7] # Mana Mitra – WhatsApp Governance
[27:3:8] - Launched **30 January 2025**; run by **RTGS**.
[27:3:9] TABLE head: Stage | Data
  [27:3:9.0] Launch (Jan 2025) | 150 services
  [27:3:9.1] 2025-26 | 865 services
  [27:3:9.2] Cap per service | 5 user inputs, 2 documents
[27:3:10] - Services: **rice card eKYC, electricity bills, 1-B Adangal, APSRTC tickets, TTD and temple darshan**.
[27:3:11] - Temples: **Rs 22.26 crore** to **21 temples**; ~30% of darshan and seva bookings via WhatsApp; top earner = **Srikalahasti** (not Tirumala).
[27:3:12] Highest temple earner through Mana Mitra = Srikalahasti, not Tirumala.

=== NOTES 5:29 | Cyber Security Concerns – Cyber Crime Types, Malware, Ransomware, Phishing, Social Engineering
## SUB 0 | Malware – Types and Mechanism
[29:0:0] - **Malware**: software designed to disrupt, damage or gain unauthorised access to a computer system.
[29:0:1] - **VIRUS** = "**Vital Information Resources Under Siege**"; a program that can **replicate itself** and spread computer to computer.
[29:0:2] # Malware Types → Mechanism → Example
[29:0:3] TABLE head: Type | Defining behaviour | Example
  [29:0:3.0] Virus | Attaches to files; user must run the infected file | Brain, Michelangelo
  [29:0:3.1] Worm | Self-replicates across networks without user interaction; fastest spreading | WannaCry
  [29:0:3.2] Trojan | Disguised as genuine software; no self-replication; opens a backdoor | Zeus
  [29:0:3.3] Ransomware | Encrypts files, demands ransom (often crypto) | AIIMS Delhi (2022)
  [29:0:3.4] Spyware | Secret surveillance; steals passwords, banking data | Pegasus
  [29:0:3.5] Adware | Unwanted ads; bundled with free/pirated software | Fireball
  [29:0:3.6] Rootkit | Administrator-level access; hides other malware; hardest to detect | Stuxnet parts
  [29:0:3.7] Keylogger | Records keystrokes (passwords, PINs, OTPs) | DarkHotel
  [29:0:3.8] Botnet | Network of hijacked "zombie" devices for DDoS, spam, crypto-mining | Mirai (IoT)
[29:0:4] - Trojan: looks genuine, tricks the user into installing it, then acts like a virus or worm.
[29:0:5] "Self-replicating without user action" = worm; "no self-replication, disguised" = trojan.

## SUB 2 | Attack Techniques and Cyber Threats
[29:2:0] TABLE head: Threat | Meaning
  [29:2:0.0] Phishing | False e-mails/texts that look legitimate, tricking users into revealing sensitive info or installing software
  [29:2:0.1] Vishing | Phishing by voice calls
  [29:2:0.2] Spam | Junk / unsolicited bulk e-mail
  [29:2:0.3] E-mail bombing | Same e-mail sent repeatedly to one address to overflow it
  [29:2:0.4] Spoofing | E-mail appears from one source but is sent from another (faked e-mail ID, caller ID, IP)
  [29:2:0.5] Man-in-the-middle | Secretly intercepts/alters communication between two parties
  [29:2:0.6] DoS / DDoS | Flooding a server with fake traffic so genuine users cannot access it; DDoS uses many machines (botnet)
  [29:2:0.7] SQL injection | Malicious database code via website input fields

=== NOTES 5:30 | Cyber Security Architecture – It Act 2000, Cert-in, Nciipc, Cyber Swachhta Kendra, I4C
## SUB 0 | It Act 2000
[30:0:0] - Purpose: **legal recognition** to transactions by **electronic data interchange** ("**e-commerce**") and electronic records; framework against computer crimes.
[30:0:1] - Concepts (Sec. 2): **electronic record, digital signature, certifying authority**.
[30:0:2] - **Special law**: may override the IPC where an offence is fully covered.
[30:0:3] - **Controller of Certifying Authorities (CCA)**: statutory regulator; licenses CAs, which issue Digital Signature Certificates.
[30:0:4] - **2008 amendment**: technology-neutral "**electronic signature**"; added sexually explicit material, **video voyeurism**, data leakage by intermediaries, e-commerce fraud (not NCCC); inserted 70A, 70B.

  [30:1:0.0] 4 / 5 | Recognition of e-records / e-signatures
