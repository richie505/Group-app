## SUB 1 | Modem, Network Devices, Servers and the OSI Model
[1:0] # Modem (asked ~15 times)
[1:1] - **Modem = MOdulator-DEModulator:** converts **digital → analog** (modulation) and **analog → digital** (demodulation) – **both** ways.
[1:2] - **Job:** the **hardware unit that connects a home computer to the internet through a telephone line**; it **interfaces telephone lines and computer equipment** and lets computers **send and receive data worldwide**.
[1:3] - It is **hardware** – not software, an OS or a voltage stabiliser; it does not encrypt or check for viruses.
[1:4] - **Statement set (UPPCS 2009):** LCD = main use of liquid crystals ✓; modem connects a computer to a phone line ✓; NIO is at **Goa** (not Coimbatore) ✗; **70 Virginis** is a **star** (not a video system) ✗ → **only 1 and 2**.
[1:5] # Devices
[1:6] TABLE head: Device | Job | OSI layer
  [1:6.0] NIC (network card) | Connects a computer to the network; holds the MAC address | 1-2 (Physical/Data Link)
  [1:6.1] Hub | Broadcasts to all ports | 1 Physical
  [1:6.2] Repeater | Regenerates a weak signal to extend the cable | 1 Physical
  [1:6.3] Switch / Bridge | Forwards frames by MAC address | 2 Data Link
  [1:6.4] Router | Connects different networks; routes by IP | 3 Network
  [1:6.5] Firewall | Filters traffic by rules | 3-4 (and above)
  [1:6.6] Gateway | Joins networks using different protocols | up to 7 Application
  [1:6.7] Modem | Signal conversion | 1 Physical
[1:7] - **Physical → application order (TS 2021):** **NIC → switch/bridge → router → firewall → gateway** (D, B, A, E, C).
[1:8] - **Router, hub and switch are all connecting devices** (MPPSC 2014 asked "which is a connecting device?" – answer "all of these").
[1:9] # Servers
[1:10] - **Proxy server:** middleman that **forwards client requests to other servers**; it does **not** provide TCP/IP addresses (DHCP does).
[1:11] - **Server types:** file, print, application, web, mail, database, proxy servers. "**Network server**" is the generic name for a powerful central computer storing shared data/programs – the MPPSC 2021 key treats it as "not a (type of) server".
[1:12] - **Nodes:** all computers and printers on a network are its **nodes**.
[1:13] # OSI model – seven layers (top to bottom)
[1:14] TABLE head: Layer | Function | Protocols / devices
  [1:14.0] 7 Application | User services | HTTP, FTP, SMTP, DNS
  [1:14.1] 6 Presentation | Encryption, compression, formats (JPEG) | –
  [1:14.2] 5 Session | Opens and closes sessions | –
  [1:14.3] 4 Transport | End-to-end delivery | TCP, UDP
  [1:14.4] 3 Network | Routing; IP addresses (Internet layer of TCP/IP) | Router
  [1:14.5] 2 Data Link | Framing, MAC addresses, error detection; Ethernet, PPP | Switch, bridge, NIC
  [1:14.6] 1 Physical | Signals on the medium | Cables, hub, repeater, modem
[1:15] - **Data Link layer** lies **between the Physical and Network layers**; OSI model ratified **1984**.
[1:16] - **SMTP** = **Application layer**; IP addresses = **Network layer**.
[1:17] > ⚠ Trap: switch = Layer 2 (MAC), router = Layer 3 (IP); modem is a Physical-layer device, not Transport.

## SUB 2 | Internet and the World Wide Web – Basics and History
[2:0] # Internet
[2:1] - **Internet = "a network of networks"**: global network of interconnected computers working on **TCP/IP**; the **largest WAN**.
[2:2] - **Uses:** send e-mail, view web pages, connect to servers – **all of the above**.
[2:3] - **How it works:** data → **packets**; **IP** directs packets, **TCP** checks errors and reassembles; **DNS** turns names into IP addresses.
[2:4] - **"Founder"/pioneer:** **Leonard Kleinrock** (packet-switching theory; first ARPANET message, 1969); Vint Cerf and Bob Kahn designed TCP/IP ("fathers of the Internet").
[2:5] # World Wide Web
[2:6] - **WWW (W3) = World Wide Web:** collection of **linked information (hypertext documents)** on computers available through the internet; accessed via **HTTP**.
[2:7] - **Inventor:** **Tim Berners-Lee** (British), **1989** at **CERN**; he also wrote the **first web browser (named "WorldWideWeb")**, the first web server, HTML, HTTP and URL. Made public in **1991**.
[2:8]   - Distractors: Bill Gates, Larry Page, Ted Nelson (coined "hypertext"), Vinod Dham (Pentium), Ray Tomlinson (e-mail), Edward Kasner ("googol").
[2:9] - **Hypermedia system:** because it **links to other computer resources** (not because it is "hyper fast").
[2:10] - Internet (infrastructure) ≠ WWW (a service running on it).
[2:11] # Timeline
[2:12] TABLE head: Year | Event
  [2:12.0] 1969 | ARPANET – US Department of Defense; forerunner of the internet
  [2:12.1] 1984 | OSI model ratified
  [2:12.2] 1986 | ERNET – India's academic network
  [2:12.3] 1989 | WWW invented by Tim Berners-Lee at CERN
  [2:12.4] 1994 | W3C founded
  [2:12.5] 1995 | VSNL launched public internet in India on 15 August 1995
  [2:12.6] 1998 | Satyam Infoway (Sify) – first private ISP of India; ICANN set up
  [2:12.7] 2003 | NIXI set up under MeitY
[2:13] # Communication basics
[2:14] - **Channel:** the **medium** through which an encoded message is transferred (sender → encoder → **channel** → decoder → receiver).
[2:15] - **Networking:** personal computers connected together form a **network**.

## SUB 3 | Protocols, DNS and Domain Names
[3:0] - **Protocol:** a **set of rules that governs data communication**; three elements – **syntax** (format), **semantics** (meaning), **timing**.
[3:1] # Protocol → function
[3:2] TABLE head: Protocol | Function
  [3:2.0] TCP/IP | Set of protocols for all transmission exchanges across the internet; the standard protocol suite for internet use/surfing
  [3:2.1] HTTP | Hypertext Transfer Protocol – used for accessing the WWW / fetching web pages
  [3:2.2] HTTPS | S = Secure – HTTP encrypted with SSL/TLS
  [3:2.3] FTP | File Transfer Protocol – exchanging files
  [3:2.4] SMTP | Sends e-mail (Application layer)
  [3:2.5] POP3 | Downloads mail to one device, usually deletes it from the server
  [3:2.6] IMAP | Keeps mail on the server, synced across devices
  [3:2.7] DHCP | Assigns IP addresses automatically
  [3:2.8] TELNET | Remote login
[3:3] - ARPANET is a network, not a protocol; CSMA/CD (Ethernet access method) and FDDI (fibre ring LAN) are not the internet protocol suite.
[3:4] # DNS
[3:5] - **DNS = Domain Name System** (not "Domain Name Server/Service"): the **database of names and addresses of internet hosts**; converts **domain names → IP addresses**.
[3:6] # Domain names
[3:7] TABLE head: Extension | Meaning
  [3:7.0] .com / .gov / .net | Commercial / government / network – all valid top-level domains
  [3:7.1] .edu | Education (.edu.us = educational institute in the USA)
  [3:7.2] .au | Australia (Austria = .at, UAE = .ae, Aruba = .aw)
  [3:7.3] .in | India (registry run by NIXI)
[3:8] - **E-mail address:** username@domainname.extension.
[3:9] > ⚠ Trap: HTML is a language, HTTP a protocol; DNS full form = Domain Name **System**.

## SUB 4 | Network Types and Topologies
[4:0] # Network types by area
[4:1] TABLE head: Type | Scope / feature
  [4:1.0] PAN | Personal area (1-10 m); Bluetooth, smartwatch-phone
  [4:1.1] LAN | A single building / small area – home, office, lab; Ethernet is an example (IEEE 802.3)
  [4:1.2] CAN | Campus Area Network – several LANs across a campus
  [4:1.3] MAN | Metropolitan Area Network – a city
  [4:1.4] WAN | Countries/continents; links LANs in different cities; the Internet is the largest WAN
  [4:1.5] VPN | Virtual Private Network – secure, encrypted network across the public internet giving users access to their organisation's network
  [4:1.6] WLAN | Wireless LAN (Wi-Fi)
[4:2] - **VPN (UPSC 2011):** answer (b) – network across the public internet giving access to the organisation's network securely; "shared pool of computing resources" = cloud computing.
[4:3] - **Network types vs topologies:** PAN/LAN/CAN/MAN/WAN are **types**; mesh, star, bus, ring are **topologies** (TS Sub Engineers key: **MAN**).
[4:4] - **APPSC 2019:** a firm linking LANs in **Mumbai, Bengaluru and New Delhi** uses a **WAN**.
[4:5] - **Intranet** = private internal network; **extranet** = controlled extension for partners; **Internet** = network of networks.
[4:6] # Topologies
[4:7] TABLE head: Topology | Layout | Resilience
  [4:7.0] Bus | All nodes on one backbone cable | Backbone break stops the whole network
  [4:7.1] Star | All nodes to a central hub/switch | A failed node is only isolated; hub failure stops all
  [4:7.2] Ring | Each node linked to two neighbours | One break can disrupt the ring
  [4:7.3] Mesh | Every node linked to every other | Most resilient; costliest – n(n-1)/2 links
  [4:7.4] Tree | Branching mix of bus and star – a generalisation of the bus topology | Exam key: topology used by the Internet
  [4:7.5] Hybrid | Mix of types | The Internet is the largest hybrid topology
[4:8] - **Grid** is **not** a common network topology.
[4:9] > ⚠ Trap: "Internet topology" – exam keys say **tree**; strictly the Internet is a hybrid (largely mesh) of networks.

## SUB 5 | IP and MAC Addressing
[5:0] TABLE head: Address | Length | Notation
  [5:0.0] IPv4 | 32 bits (~4.3 billion addresses) | Dotted decimal, 4 octets each 0-255, e.g. 192.168.1.1
  [5:0.1] IPv6 | 128 bits | 8 groups of hexadecimal separated by colons
  [5:0.2] MAC (Media Access Control) | 48 bits (6 bytes, 12 hex digits) | Unique ID burnt into the NIC; used at the Data Link layer
[5:1] - **IP address** = the unique number that **identifies a computer on the internet** (not e-mail or street address; SMTP/TCP/UDP are protocols).
[5:2] - **IPv4 needs fewer bits than IPv6** (32 < 128) (APPSC G1).
[5:3] - **Invalid IPv4:** "192.23.350" – only three octets and 350 > 255.
