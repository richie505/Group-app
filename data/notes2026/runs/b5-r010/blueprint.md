## 3. Angles
- **Factual recall** of "who won / for what / which year" ≈ 80% (one-liners from SSC, UPPSC, APPSC screening papers).
- **Repeats:** Einstein–photoelectric effect (8 papers), Alfred Nobel–dynamite (4), Raman 1930 (4), Tagore 1913 (4), VSSC in Kerala (2), Fields Medal = Nobel of maths (2, identical APPSC G2 2017 papers), Ostrom first woman Economics (2).
- **Match / pairs:** IAS 2007 (Sarabhai, Husain, Amjad Ali Khan), TSPSC 2023 pairs, APPSC 2024 matches of 2019 and 2024 laureates.
- **NOT / wrong pair:** "not a Nobel winner" (J.C. Bose, Bhabha), "NOT correct about the Nobel" (Khorana shared), 2019 incorrect pair (Tokarczuk).
- **Chronology:** TSPSC 2023 (Golgi-Cajal 1906 → Loewi 1921 → double helix 1953).
- **Current linkage:** recent-year laureates (2016-2024), RVP 2024, CR Rao statistics prize 2023; APPSC now asks the latest year's Nobel list as a match.
