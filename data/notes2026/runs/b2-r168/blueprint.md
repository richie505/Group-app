## 5. Key corrections worth knowing
- **SES 2021-22 statements (Sample Taker 2023):** Rythu Bharosa's Rs 13,500 *includes* the Rs 6,000 PM-KISAN share, so both statements are true (printed "Only I").
- **Rythu Bharosa per year (DL 2020):** none of 20,500/10,500/14,500/12,500 is right; Rs 13,500 added (Rs 12,500 was only the 2019 promise).
- **Pedarikampai Gelupu (Group-II 2019):** the welfare corporations' portal; scholarships run on Jnanabhumi, so "All of the above" is wrong.
- **Budget 2019-20 Rythu Bharosa:** Rs 8,750 crore (the starred Rs 8,570 in some books is a misprint).
