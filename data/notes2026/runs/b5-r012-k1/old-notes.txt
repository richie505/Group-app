## SUB 0 | Memory and Storage – Units, Primary and Secondary Memory
[12:0:0] # Units in order
[12:0:1] - **Bit** (binary digit) = the **smallest unit** of data/information; **nibble = 4 bits**; **byte = 8 bits** (APPSC 2025; asked 6 times).
[12:0:2] - **Order:** bit < nibble < byte < **KB** < MB < GB < TB < PB < EB < ZB < YB.
[12:0:3] TABLE head: Unit | Equals
  [12:0:3.0] 1 byte | 8 bits
  [12:0:3.1] 1 KB | 1024 bytes = 8192 bits
  [12:0:3.2] 1 MB | 1024 KB (about a million characters)
  [12:0:3.3] 1 GB | 1024 MB (about one billion characters)
  [12:0:3.4] 1 TB | 1024 GB
[12:0:4] - **Smallest time unit** among those asked: **picosecond** (10⁻¹²) < nanosecond (10⁻⁹) < microsecond (10⁻⁶) < second (APPSC G1 2004).
[12:0:5] # Primary memory
[12:0:6] TABLE head: Memory | Nature
  [12:0:6.0] RAM (Random Access Memory) | Primary, volatile, temporary working store – lost when power goes off; not like hard-disc storage; SRAM = cache (faster), DRAM = main memory; RAM sticks use DDR (Double Data Rate)
  [12:0:6.1] ROM (Read-Only Memory) | Non-volatile, permanent memory built into the computer; holds firmware/BIOS (Basic Input-Output System); PROM, EPROM, EEPROM
  [12:0:6.2] Cache | Small, extremely fast memory between CPU and main memory; a portion the processor reaches faster than regular RAM; shortest access time; speeds up processing; made of SRAM
  [12:0:6.3] Registers | Fastest memory, embedded on the CPU chip (electronic memory)
  [12:0:6.4] Memory | Erased by
  [12:0:6.5] EPROM | Ultraviolet light
  [12:0:6.6] EEPROM | Electrically
[12:0:7] - **Speed order:** registers > cache > RAM > SSD > HDD > optical disc > magnetic tape.
[12:0:8] - **Static RAM is faster than dynamic RAM**; **primary storage is faster than secondary** (a statement saying the reverse is wrong).
[12:0:9] - **Memory types:** **semiconductor** (primary), **magnetic** and **optical** (secondary) – "server" is not a memory type.
[12:0:10] - **Virtual memory:** its size (virtual address space) depends on the CPU's **address lines** (32 lines → 2³² bytes).
[12:0:11] - **ROM is a memory, not a computer language.** **DIMM = Dual In-line Memory Module** (RAM stick; older SIMM; laptops SO-DIMM).
[12:0:12] # Secondary storage
[12:0:13] TABLE head: Storage | Fact
  [12:0:13.0] HDD | Magnetic disk, non-volatile; first commercial hard disk drive by IBM (RAMAC 350, 1956); SATA hard disk = magnetic, not capacitive memory
  [12:0:13.1] SSD | Flash memory, no moving parts, faster
  [12:0:13.2] Magnetic tape | Sequential access, slowest; backup and archival
  [12:0:13.3] Flash drive / pen drive | EEPROM-based flash; keeps data without power; low power; costlier, not cheaper, than mechanical disk drives
  [12:0:13.4] CD-ROM (Compact Disc Read Only Memory) | about 700 MB
  [12:0:13.5] DVD (Digital Versatile Disc) | 4.7 GB single layer; 8.5 GB dual layer
  [12:0:13.6] Blu-ray | 25 GB single layer; 50 GB dual layer – stores more than a DVD
[12:0:14] - **Capacity order (decreasing):** Blu-ray > **DVD > CD-ROM > floppy disk**.
[12:0:15] - **RAM is NOT secondary memory**; SSD, hard disk, optical disk, flash drive, floppy and USB pen drive are.
[12:0:16] > Statement angle: "RAM is non-volatile" ✗; "primary is slower than secondary" ✗; "SRAM faster than DRAM" ✓; "Von Neumann = stored-program digital computer" ✓ → answer C and D.

## SUB 1 | CPU and Hardware Components
[12:1:0] # CPU – the brain
[12:1:1] - **CPU = Central Processing Unit** (NOT "Control Processing Unit") – the **brain**, the **controlling unit** and the **most important part** of the computer; most processing happens here (asked 9 times).
[12:1:2] - **CPU is hardware**, not software – a statement "the CPU is the software that carries out instructions" is false.
[12:1:3] - **Processor parts:** **Control Unit + ALU** (with registers); main memory and storage are **not** parts of the processor.
[12:1:4] TABLE head: Component | Function
  [12:1:4.0] ALU (Arithmetic Logic Unit) | Arithmetic and logical operations – performs calculations and makes decisions
  [12:1:4.1] CU (Control Unit) | Fetches and decodes program instructions, makes control signals, directs the other units
  [12:1:4.2] Registers | Fastest storage inside the CPU (address, data, instruction registers)
  [12:1:4.3] PSU | Only supplies power
[12:1:5] - **Main components of a computer:** input unit, output unit, processing unit, memory unit, secondary storage – **"basic unit" is not a component**.
[12:1:6] - **After a double-click** of the mouse, information goes to the **CPU**.
[12:1:7] # Buses, chips and processors
[12:1:8] - **Buses:** the wire pathways that **connect the different parts** of a computer (data, address and control buses).
[12:1:9] - **IC chips are made of silicon** (a semiconductor) – not silica (SiO₂), gold, chromium or iron oxide.
[12:1:10] - **Celeron, Pentium, Core** = series of Intel **processors**; **Intel Core i9** = high-end processor with **8 to 24 cores**.
[12:1:11] - **Clock speed** of a processor is measured in **hertz – gigahertz (GHz)**.
[12:1:12] - **IBM = International Business Machine(s)**.
[12:1:13] - **Modem = modulator-demodulator**: converts digital data into analog signals and back – "all of the above".
[12:1:14] - **UPS = Uninterrupted Power Supply** (keeps the computer running briefly when power fails); **SMPS = Switched Mode Power Supply** (rectified AC to low-voltage DC).
[12:1:15] - **Peripheral device:** equipment added to a computer to enhance its functionality (printer, scanner, webcam).

## SUB 4 | Computer Types and Supercomputers
[12:4:0] TABLE head: Type | Feature / example
  [12:4:0.0] Analog | Continuous quantities – car speedometer, thermometer
  [12:4:0.1] Digital | Discrete (binary) data – PCs; works on the logical principle (Boolean 0/1)
  [12:4:0.2] Hybrid | Analog + digital features; converts analog output into digital form – ICU monitors, ECG
  [12:4:0.3] Micro / personal | Most widely used – desktop, laptop, tablet, smartphone, wearables
  [12:4:0.4] Embedded | Dedicated function inside a larger system – digital watch
  [12:4:0.5] Supercomputer | Largest, fastest and costliest; speed in FLOPS

## SUB 5 | Software, Office Tools and Operating Systems

  [12:5:2.0] System software | OS (Windows, Linux, macOS, Android, iOS), device drivers, utilities, firmware, translators

## SUB 7 | ICT – Nature, Scope and Terms
[12:7:0] - **ICT = Information and Communication Technology**: devices and applications used to **access, store, transmit and manipulate digital information** – hardware, software, networks, data, people, services and infrastructure.
[12:7:1] - **Aim:** smooth **human-human, human-machine and machine-machine (M2M)** communication.
[12:7:2] - **Information Technology** = **connectivity + hardware** in the printed key (JPSC 2016); also taught as computers + communication.
[12:7:3] - **Concerns:** privacy, **digital divide**, job insecurity, over-reliance. **Positive impact of the internet:** best source of knowledge at a click.
[12:7:4] - **Cybernetics:** study of **automation and communication between human and machine** – term by **Norbert Wiener**.
[12:7:5] - **Artificial Intelligence** makes machines intelligent and mimics human actions.
[12:7:6] - **Technology preservation** = **computer museum** (APPSC 2019).
[12:7:7] - **IT terms:** cyberspace, upload, modem ✓ – **"light storage" is not an IT term**.
[12:7:8] - **Smart card:** plastic card with an **embedded microchip**; **digital technology** works with satellite and fibre-optic transmission; a **digital library is NOT only on the internet** (UPSC 2002 → I and II).
[12:7:9] - **Aarogya Setu, CoWIN, DigiLocker, DIKSHA** – all on **open-source digital platforms**.
