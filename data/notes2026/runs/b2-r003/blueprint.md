## 4. Problems for the owner
- **Five PYQs are not polity** but sit in this row: Gagné's hierarchy of learning (8 types), Flag Code 2002 (3 Parts), agnosia, animal phyla match, "not an active agency of education". Book 2 has no row for them, so they are keyed and mapped to a small last sub-section ("Stray PYQs Filed Here"). They should be moved to the right book (education psychology / biology / national symbols) when the app has such rows.
- **y2cdee37b625** (agencies of education): the printed key "State" contradicts the standard lists (the State is an active agency), and no source classifies "factory and workshop". Set to -1.
- **UPSC 2020 (ya230b95cb69):** keyed "Only II" (Arts. 13, 32, 226 explicitly confer judicial review – NextGen p.324). The UPSC official key is D ("Neither"); this is noted in the explanation.
- **UPSC 2021 (y844277c5895):** printed key "1 only" was wrong; the UPSC official key is C ("Both"). Changed.
- **UPPSC 2009 (yaca4a5f67da):** "unified authority" is a doubtful item; kept "All of these" (the exam key), marked ambiguous.
