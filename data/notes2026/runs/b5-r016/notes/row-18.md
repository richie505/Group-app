=== Cloud Computing
- **Cloud computing** = hosted computing services (storage, servers, databases, software) over the internet **on demand**, pay-as-you-go.
- Features: on-demand self-service, broad network access, **resource pooling** (many users share resources), **elasticity** (resources grow/shrink with demand), measured service.
| Model | User gets | Example |
|---|---|---|
| **IaaS** | Servers, storage, network | **Amazon EC2**, AWS |
| **PaaS** (**Platform as a Service**) | Platform to develop, test, deploy, run apps | **Google App Engine** |
| **SaaS** | Ready software over the web; mobile access, customisable | Gmail, Outlook |
- **Not a separate layer:** "**Hardware as a Service**" (comes under IaaS); **allotment of electromagnetic spectrum** is not a cloud service.
- Deployment models: public, private, hybrid, community ("platform cloud" is not one).
| Storage service | Company |
|---|---|
| **SkyDrive** (now OneDrive) | **Microsoft** |
| S3 | Amazon Web Services |
| iCloud / Google Drive / Dropbox | Apple / Google / Dropbox |
- **MeghRaj (GI Cloud):** Government of India cloud for e-services on **NIC** infrastructure.

=== Big Data and Data Analytics
- **Big data** = large volume of **high-velocity, complex and variable** data (APPSC key).
- Classic **3 Vs: Volume, Velocity, Variety**; **Veracity** and **Value** added later.
| Term | Meaning |
|---|---|
| Data mining | Finding patterns in large datasets |
| Data warehouse | Cleaned, **structured** data for analysis |
| Data lake | **Raw** data in native format |
| Metadata | Data about data |
| **R** | Language used for **statistical computing** |
- **APPSC 2025:** AI, quantum computing and data science improve environmental management by **analysing large datasets** to predict pollution, optimise resources and simulate climate models.
- **NDGF Policy (MeitY, 2022):** India Data Management Office + India Datasets Programme. **OGD Platform** (NDSAP **2012**). IndiaAI Datasets Platform = **AI-Kosh**.
- India: member of the **UN Committee of Experts on Big Data and Data Science** and its Advisory Board. **ES 2025-26:** UDISE+, AISHE, ABDM surveys + AI for health hotspots.

=== Data Centres
- **HyperVault AI Data Centre Ltd:** **TCS + TPG** joint venture (2025) for AI-focused, sovereign data centres.
- Capacity: **375 MW (2020) → 1.57 GW (2026) → ~8 GW (2030)**; **Mumbai** largest share (~52%).
- **PUE** = total facility energy ÷ IT energy; **closer to 1 = better** (1.1 best). **Uptime Tier IV**: fully fault-tolerant, **~99.995%**.
- **Draft Data Centre Policy (Sep 2025):** **20-year** tax holiday (not 10). Data centres use ~**1%** of global electricity.
- **Visakhapatnam:** projected biggest hub (~6 GW over 10 years); Vizag–Kapuluppada corridor in **Seismic Zone II**; submarine cables, sea-breeze cooling, nearness to **Southeast Asia** (not the EU); **Google $15 billion, 1 GW AI hub** (Oct 2025); **TCS – HyperVault**.

=== Edge, Fog, Serverless and Containers
| Model | Where | Feature |
|---|---|---|
| Cloud | Distant central data centres | Heavy storage, analytics |
| **Fog** | **Between edge and cloud** | Local aggregation |
| **Edge** | **On / near the device** | **Lowest latency**; saves bandwidth |
- **Virtualisation:** one server runs many VMs, each with its own OS. **Containers** (Docker) are lighter – **share the host OS kernel**.
- **Serverless:** provider runs and scales servers, bills per use (AWS Lambda).
