=== MS Office, Windows and Tally – Features Asked
# Word and PowerPoint
| Feature | What it does |
|---|---|
| **Mail Merge** (Word) | Produces **bulk personalised letters** from one main document + a data list (templates only give a layout; Envelopes prints single envelopes) |
| **Ctrl + End** (Word) | Moves to the **bottom (end) of the document**; End alone = end of the current line; Ctrl + Home = top |
| **Motion path** (PowerPoint) | An animation that **moves an item such as a picture along a path on a slide** |
| **Transitions** (PowerPoint) | **Effects that introduce slides** – the visual effect as one slide gives way to the next (animations act on objects within a slide) |
| **Slide Sorter view** (View tab) | Shows **all slides as thumbnails on one screen**; Slide Show runs them one by one; Master view edits the template |
# Excel and Access
| Feature | What it does |
|---|---|
| **Nested function** | A function used **inside another function**, e.g. =ROUND(SUM(A1:A5),0) |
| **Goal Seek** | **What-If Analysis** tool that finds the input needed for a target result (other What-If tools: Scenario Manager, Data Table) |
| **AutoComplete** | When you start typing a value already in the column, Excel **suggests the rest of the entry** (AutoFill extends a series; AutoCorrect fixes typos) |
| **Lookup Wizard** (Access) | Makes a field that **selects its value from another table** (or a value list) |
# Windows and Tally
- **Title-bar buttons:** **minus (–) = minimise**, square = maximise/restore, × = close.
- **My Computer / This PC:** shows the drives and the **used and free space** on each.
- **Tally:** **Ctrl + Q** = quit from the **Gateway of Tally** (or the current screen). Tally ERP 9 voucher keys: **Alt + 2 = duplicate**, **Alt + A = add**, **Alt + I = insert**, **Alt + D = delete** (a voucher, a master, or a company in Company Alteration) – all four valid, so "which is incorrect" has no correct option.
- **Microsoft** headquarters: **Redmond, Washington** (USA) – not California.

=== Data, Information and Knowledge
- **Datum** = singular of data – **a single piece of information** (a fact).
- **Information** = **processed (organised) data** that has meaning; **communicated information = a message**.
- **Information vs knowledge:** information is piecemeal, **fragmented** and particular; knowledge is **structured** and coherent.
- **Digitisation** = the process by which text, images, sound or video are made into **computer-readable (digital) form**.
- **Primary sources of information** = original records: **patents, standards, theses, journal articles** (secondary = indexes, reviews, textbooks).
- **Critical abstract:** describes the content of a work **and also evaluates** it and its presentation (informative / indicative abstracts only describe).
- **Encapsulation** (digital preservation): a digital object is packaged with its metadata and the information needed to render it later.
- **Inferential statistics:** the **sampling procedure** used decides how far sample results can be generalised to the population.

=== Databases – DBMS, RDBMS and SQL
- **Database** = an **organised collection of data that can be stored, manipulated and retrieved** (not read-only, not only numbers, not merely a backup).
- **RDBMS** = a **collection of tables** (relations) made of records (rows) and fields (columns).
- **SQL = Structured Query Language** – manages relational databases.
| SQL command | Type | Does |
|---|---|---|
| **ALTER** | DDL | **Modifies the structure** of a table/database |
| UPDATE | DML | Changes the data in rows |
| REVOKE | DCL | Removes privileges |
- **Cardinality** (ER model) = the **number of times an entity of an entity set participates in a relationship set** – one-to-one, one-to-many, many-to-many (not the number of entities or attributes).
