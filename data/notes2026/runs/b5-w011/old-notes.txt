## SUB 4 | Nobel Prize Basics
[11:4:0] - **Alfred Nobel** (Swedish chemist) invented **dynamite (1867)** – not cosmic rays (Victor Hess), dynamo, penicillin, typewriter or gramophone.
[11:4:1] - **Will 1895**; Nobel Foundation **1900**; **first prizes 1901**; instituted by **Sweden** (Peace Prize given in Norway).
[11:4:2] - **Original five:** Physics, Chemistry, Physiology or Medicine, Literature, Peace. **No Nobel for mathematics.**
[11:4:3] - **Economics:** set up by **Sveriges Riksbank (Sweden's central bank)** in **1968**, first given **1969** – not in the will.
[11:4:4] - **How many each year:** **six** (books and keys); strictly five Nobel Prizes + the Riksbank memorial prize.
[11:4:5] - Laureate status cannot be transferred, shared or withdrawn; only the medal can change hands.
[11:4:6] - **RDX** (cyclonite, patented **1898**) – **Georg Friedrich Henning**, Germany, not Nobel.

## SUB 5 | Shanti Swarup Bhatnagar Prize and Rashtriya Vigyan Puraskar
[11:5:0] # Bhatnagar Prize
[11:5:1] - **S.S. Bhatnagar:** "Father of Research Laboratories"; **founder-director and first DG of CSIR**.
[11:5:2] - **Prize:** by **CSIR since 1958** – India's best-known **science and technology** prize; age limit **45**; **7 disciplines** (biology, chemistry, earth/atmosphere/ocean/planetary, engineering, mathematics, medicine, physics – **not political science**).
[11:5:3] - **2010 awardees:** included **Sanjeev Galande**. **Madhav Gadgil** (died Jan 2026) – People's Biodiversity Registers, **Gadgil Commission 2010** (Western Ghats).
[11:5:4] # Rashtriya Vigyan Puraskar (RVP)
[11:5:5] - **Instituted 2023**, **first awarded Aug 2024** (exam key: **2024**); highest S&T honour; **13 domains**; replaced 300-odd ministry awards; medal + citation, no cash.

  [11:5:6.0] Vigyan Ratna | Lifetime – first G. Padmanabhan (2024); J.V. Narlikar (posthumous, 2026 list)

  [11:5:6.2] Vigyan Yuva-SSB | Young scientists up to 45 (Bhatnagar Prize absorbed)

## SUB 1 | Memory and Storage – Units, Primary and Secondary Memory
[12:1:0] # Units in order

[12:1:6] TABLE head: Memory | Nature

  [12:1:6.4] Memory | Erased by
  [12:1:6.5] EPROM | Ultraviolet light
  [12:1:6.6] EEPROM | Electrically

[13:1:7] - **Physical → application order (TS 2021):** **NIC → switch/bridge → router → firewall → gateway** (D, B, A, E, C).
[13:1:8] - **Router, hub and switch are all connecting devices** (MPPSC 2014 asked "which is a connecting device?" – answer "all of these").
[13:1:9] # Servers
[13:1:10] - **Proxy server:** middleman that **forwards client requests to other servers**; it does **not** provide TCP/IP addresses (DHCP does).
[13:1:11] - **Server types:** file, print, application, web, mail, database, proxy servers. "**Network server**" is the generic name for a powerful central computer storing shared data/programs – the MPPSC 2021 key treats it as "not a (type of) server".
[13:1:12] - **Nodes:** all computers and printers on a network are its **nodes**.
[13:1:13] # OSI model – seven layers (top to bottom)
[13:1:14] TABLE head: Layer | Function | Protocols / devices
  [13:1:14.0] 7 Application | User services | HTTP, FTP, SMTP, DNS
  [13:1:14.1] 6 Presentation | Encryption, compression, formats (JPEG) | –
  [13:1:14.2] 5 Session | Opens and closes sessions | –
  [13:1:14.3] 4 Transport | End-to-end delivery | TCP, UDP
  [13:1:14.4] 3 Network | Routing; IP addresses (Internet layer of TCP/IP) | Router
  [13:1:14.5] 2 Data Link | Framing, MAC addresses, error detection; Ethernet, PPP | Switch, bridge, NIC
  [13:1:14.6] 1 Physical | Signals on the medium | Cables, hub, repeater, modem

[13:1:16] - **SMTP** = **Application layer**; IP addresses = **Network layer**.

## SUB 2 | Internet and the World Wide Web – Basics and History
[13:2:0] # Internet
[13:2:1] - **Internet = "a network of networks"**: global network of interconnected computers working on **TCP/IP**; the **largest WAN**.
[13:2:2] - **Uses:** send e-mail, view web pages, connect to servers – **all of the above**.
[13:2:3] - **How it works:** data → **packets**; **IP** directs packets, **TCP** checks errors and reassembles; **DNS** turns names into IP addresses.
[13:2:4] - **"Founder"/pioneer:** **Leonard Kleinrock** (packet-switching theory; first ARPANET message, 1969); Vint Cerf and Bob Kahn designed TCP/IP ("fathers of the Internet").
[13:2:5] # World Wide Web
[13:2:6] - **WWW (W3) = World Wide Web:** collection of **linked information (hypertext documents)** on computers available through the internet; accessed via **HTTP**.
[13:2:7] - **Inventor:** **Tim Berners-Lee** (British), **1989** at **CERN**; he also wrote the **first web browser (named "WorldWideWeb")**, the first web server, HTML, HTTP and URL. Made public in **1991**.
[13:2:8]   - Distractors: Bill Gates, Larry Page, Ted Nelson (coined "hypertext"), Vinod Dham (Pentium), Ray Tomlinson (e-mail), Edward Kasner ("googol").
[13:2:9] - **Hypermedia system:** because it **links to other computer resources** (not because it is "hyper fast").
[13:2:10] - Internet (infrastructure) ≠ WWW (a service running on it).
[13:2:11] # Timeline
[13:2:12] TABLE head: Year | Event
  [13:2:12.0] 1969 | ARPANET – US Department of Defense; forerunner of the internet
  [13:2:12.1] 1984 | OSI model ratified
  [13:2:12.2] 1986 | ERNET – India's academic network
  [13:2:12.3] 1989 | WWW invented by Tim Berners-Lee at CERN
  [13:2:12.4] 1994 | W3C founded
  [13:2:12.5] 1995 | VSNL launched public internet in India on 15 August 1995
  [13:2:12.6] 1998 | Satyam Infoway (Sify) – first private ISP of India; ICANN set up
  [13:2:12.7] 2003 | NIXI set up under MeitY
[13:2:13] # Communication basics
[13:2:14] - **Channel:** the **medium** through which an encoded message is transferred (sender → encoder → **channel** → decoder → receiver).
[13:2:15] - **Networking:** personal computers connected together form a **network**.

## SUB 3 | Protocols, DNS and Domain Names
[13:3:0] - **Protocol:** a **set of rules that governs data communication**; three elements – **syntax** (format), **semantics** (meaning), **timing**.
[13:3:1] # Protocol → function
[13:3:2] TABLE head: Protocol | Function
  [13:3:2.0] TCP/IP | Set of protocols for all transmission exchanges across the internet; the standard protocol suite for internet use/surfing
  [13:3:2.1] HTTP | Hypertext Transfer Protocol – used for accessing the WWW / fetching web pages
  [13:3:2.2] HTTPS | S = Secure – HTTP encrypted with SSL/TLS
  [13:3:2.3] FTP | File Transfer Protocol – exchanging files
  [13:3:2.4] SMTP | Sends e-mail (Application layer)
  [13:3:2.5] POP3 | Downloads mail to one device, usually deletes it from the server
  [13:3:2.6] IMAP | Keeps mail on the server, synced across devices
  [13:3:2.7] DHCP | Assigns IP addresses automatically
  [13:3:2.8] TELNET | Remote login
[13:3:3] - ARPANET is a network, not a protocol; CSMA/CD (Ethernet access method) and FDDI (fibre ring LAN) are not the internet protocol suite.

[13:4:7] TABLE head: Topology | Layout | Resilience
  [13:4:7.0] Bus | All nodes on one backbone cable | Backbone break stops the whole network
  [13:4:7.1] Star | All nodes to a central hub/switch | A failed node is only isolated; hub failure stops all
  [13:4:7.2] Ring | Each node linked to two neighbours | One break can disrupt the ring
  [13:4:7.3] Mesh | Every node linked to every other | Most resilient; costliest – n(n-1)/2 links

## SUB 1 | Semiconductors and Indigenous Chips
[15:1:0] # Basics
[15:1:1] - **Silicon** = the **semiconductor** used for computer (IC) chips (exam key for "newest substance in chips"; strictly **gallium arsenide** is the newer compound semiconductor).
[15:1:2] - **Not a semiconductor:** **Krypton** (noble gas); silicon, germanium, selenium are.
[15:1:3] - **p-type:** trivalent doping → **holes** = majority carriers; n-type → electrons.
[15:1:4] - **Diode:** current one way only → **AC to DC** (rectification); a **semiconductor diode is non-ohmic** (copper coil, heater coil, rheostat are ohmic).
[15:1:5] - **Silicon carbide** (carborundum): very hard → abrasive for **cutting very hard substances**; also a power semiconductor.
[15:1:6] - **Piezoelectric MEMS** (May 2023): **IIT Madras + DRDO** (NPOL) – PZT thin-film **underwater** acoustic sensor for Navy SONAR.
