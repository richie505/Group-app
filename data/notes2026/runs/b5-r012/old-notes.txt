=== NOTES 5:12 | Nature and Scope of Ict; Hardware, Software, Memory and Operating Systems
## SUB 0 | Nature and Scope of Ict
[12:0:0] - **ICT = Information and Communications Technology**: umbrella term for any device or application used to **access, store, transmit and manipulate digital information** – mobiles, networks, software, internet, satellites; access to information through telecommunications (internet, wireless networks, cellphones).
[12:0:1] - Aim: smooth **human-human, human-machine and machine-machine (M2M)** communication.
[12:0:2] - Concerns: privacy risks, **digital divide**, job insecurity, over-reliance on technology.
[12:0:3] - A computer's strengths – **all of**: high speed, accuracy and memory (temporary and permanent).
[12:0:4] - **Artificial Intelligence** boosts human abilities by making machines intelligent and mimicking human actions.
[12:0:5] - **Cybernetics**: study of automation and communication between human and machine – term by **Norbert Wiener**.
[12:0:6] - **Technology preservation** = computer museum (APPSC 2019).
[12:0:7] - **Aarogya Setu, CoWIN, DigiLocker, DIKSHA** – all four built on **open-source digital platforms**.

## SUB 2 | Computer Types
[12:2:0] TABLE head: Type | Feature / example
  [12:2:0.0] Analog | Continuous quantities – car speedometer, thermometer
  [12:2:0.1] Digital | Discrete (binary) data – PCs
  [12:2:0.2] Hybrid | Both – ICU monitors, ECG
  [12:2:0.3] Personal / micro | Desktop, laptop, tablet, smartphone, wearables (smartwatch, fitness tracker, AR glasses)
  [12:2:0.4] Embedded | Dedicated function inside a larger system – digital watch
  [12:2:0.5] Supercomputer | Largest, fastest and costliest; speed in FLOPS
  [12:2:0.6] Quantum computer | Uses qubits (superposition, entanglement); fast calculation, cryptography, optimisation
[12:2:1] - **Fax and email over phone lines** use **both analog and digital** signals.
[12:2:2] - Quantum computer is described as the smallest and fastest computer copying brain working. Oxford University researchers made **10 billion quantum entanglements** in silicon.
[12:2:3] - **Q-Day**: when quantum computers may break **RSA-2048** encryption using **Shor's algorithm (1994)**.
## SUB 3 | Hardware – Cpu and Components
[12:3:0] # CPU
[12:3:1] - **CPU = Central Processing Unit** (NOT "Control Processing Unit") – the **brain** and most important part; most calculations happen here.
[12:3:2] TABLE head: Component | Function
  [12:3:2.0] ALU (Arithmetic Logic Unit) | Arithmetic and logical operations; calculations and decisions
  [12:3:2.1] CU (Control Unit) | Fetches and decodes instructions, makes control signals, directs
  [12:3:2.2] Registers | Fastest storage inside the CPU
  [12:3:2.3] PSU | Only supplies power
[12:3:3] - After a **double-click** of the mouse, information goes to the **CPU**.
[12:3:4] - Main components: input/output devices, processing unit, memory unit, secondary storage – **"basic unit" is not a component**.
[12:3:5] # Processors and Power
[12:3:6] - **Celeron, Pentium, Core** = series of processors; **Intel Core i9** = high-end CPU with **8 to 24 cores**; multi-core CPUs.
[12:3:7] - **IBM = International Business Machine(s)**.
[12:3:8] - **UPS = Uninterrupted Power Supply** – keeps the computer running briefly when power fails.
[12:3:9] - **SMPS = Switched Mode Power Supply** – changes rectified AC input into low-voltage DC.
[12:3:10] - **Modem** – hardware linking telephone lines and computer equipment.

## SUB 5 | Memory and Storage
[12:5:0] # Units in Order
[12:5:1] - **Bit** (binary digit) = smallest unit; memory is measured in bits. **Nibble = 4 bits**; **byte = 8 bits** (APPSC 2025).
[12:5:2] - Order: bit < nibble < byte < **KB** < MB < GB < TB < PB < EB < ZB < YB.
[12:5:3] TABLE head: Unit | Equals
  [12:5:3.0] 1 byte | 8 bits
  [12:5:3.1] 1 KB | 1024 bytes = 8192 bits
  [12:5:3.2] 1 MB | 1024 KB
  [12:5:3.3] 1 GB | 1024 MB
  [12:5:3.4] 1 TB | 1024 GB
[12:5:4] Smallest of the units asked (KB, MB, GB, TB) = KB.
[12:5:5] # Primary Memory
[12:5:6] TABLE head: Memory | Nature
  [12:5:6.0] RAM (Random Access Memory) | Volatile, temporary working store, lost when power goes off; SRAM = cache, DRAM = main memory
  [12:5:6.1] ROM (Read-Only Memory) | Non-volatile, permanent, can only be read; holds firmware/BIOS (Basic Input-Output System); PROM, EPROM, EEPROM
  [12:5:6.2] Cache | Small, fastest memory between CPU and RAM; shortest access time, highest bandwidth; speeds up processing
  [12:5:6.3] Memory | Erased by
  [12:5:6.4] EPROM | Ultraviolet light
  [12:5:6.5] EEPROM | Electrically
[12:5:7] - **ROM is a memory, not a computer language.**
[12:5:8] - **DIMM = Dual In-line Memory Module** (RAM stick, contacts on both sides; older **SIMM**; laptops use SO-DIMM).
[12:5:9] - Memory types: **semiconductor** (primary), **magnetic** and **optical** (secondary) – "server" is not one.
[12:5:10] # Secondary Storage
[12:5:11] TABLE head: Storage | Fact
  [12:5:11.0] HDD | Magnetic disk; non-volatile
  [12:5:11.1] SSD | Flash memory, no moving parts, faster
  [12:5:11.2] Magnetic tape | Sequential access, slowest; backup and archival
  [12:5:11.3] Flash drive / memory card | EEPROM-based flash; keeps data without power; not cheaper than mechanical disks
  [12:5:11.4] CD | about 700 MB
  [12:5:11.5] DVD | 4.7 GB single layer; 8.5 GB dual layer
  [12:5:11.6] Blu-ray | 25 GB single layer; 50 GB dual layer
[12:5:12] - **RAM is NOT secondary memory**; SSD, hard disk and USB pen drive are.
[12:5:13] - Magnetic tape and magnetic disk both store very large data; the **disk stores more**.
[12:5:14] Speed order: registers > cache > RAM > SSD > HDD > optical disc > magnetic tape
## SUB 6 | Software Types
[12:6:0] - **Software** = another name for computer programs; two major types: **application** and **system**.
[12:6:1] TABLE head: Type | Examples
  [12:6:1.0] System software | OS, device drivers, translators (compiler, interpreter, assembler)
  [12:6:1.1] Utility software | Antivirus, disk cleanup, backup, compression
  [12:6:1.2] Application software | MS Word, spreadsheets, photo/video/audio editing, DTP, CAD, browsing, gaming; graphics (Photoshop, CorelDRAW); multimedia (players, editors); database (Oracle, MySQL, MS Access); MS Outlook (e-mail, calendar, contacts)
[12:6:2] - **Device driver** = system software, not application.
[12:6:3] - **Word processing software**: Microsoft Word, **WordStar** (MicroPro International) – all options given are correct.
[12:6:4] - **Microsoft Office** = office suite (Word, Excel, PowerPoint), **not an OS**.
[12:6:5] - **Multimedia**: text joined with audio, video, voiceover, animation and graphics in one digital presentation.
[12:6:6] - **Compiler** and **assembler** are **not hardware** – they are programs.
[12:6:7] - A Word document, video or MP3 is a **file**; the **extension** shows its type (.doc = Word).
[12:6:8] # Open Source
[12:6:9] - **Open-source**: source code free to view, modify and share under its licence (unlike proprietary).
[12:6:10] - **GNU ("GNU's Not Unix")**: free, **Unix-like** OS software, so compatible with Unix; **Linux** kernel by Torvalds.
[12:6:11] - **Internet Explorer** = **closed source**.
## SUB 7 | Operating Systems
[12:7:0] - **Functions**: manages hardware; gives user interface; handles processes, memory, file systems, device drivers, security and I/O.
[12:7:1] TABLE head: OS type | Feature / example
  [12:7:1.0] Time-sharing / multi-user | Many users share CPU time – UNIX
  [12:7:1.1] Real-time | Fixed response deadlines – missile guidance, air-traffic control, medical devices (hard vs soft)
  [12:7:1.2] Mobile | Android (Linux-based, Google), iOS (Apple), BharOS (IIT Madras)
[12:7:2] # Interfaces and Examples
[12:7:3] TABLE head: Interface | Example
  [12:7:3.0] CLI (command-line, non-graphical) | MS-DOS, UNIX shell
  [12:7:3.1] GUI (icons, windows, mouse) | Windows, macOS
[12:7:4] - **MS-DOS**: Microsoft, **August 1981**; written by **Tim Paterson** from 86-DOS, for IBM-compatible PCs; eight versions.
[12:7:5] - **UNIX**: multi-user OS, made **1969** by **AT&T**; **kernel** = main part; UNIX = kernel + shell + commands + applications.
[12:7:6] - **Windows 3** – 1990; **Windows 11** – October 2021.
[12:7:7] - **Android 6.0 = Marshmallow** (shown May 2015, released October 2015).
[12:7:8] - **Linux, Windows, Unix** = OSs; MS Office is not.
[12:7:9] - **Batch OS:** groups similar jobs and runs them one after another without user interaction.
## SUB 8 | Programming, Number Systems and Logic
[12:8:0] # Language Levels
[12:8:1] TABLE head: Level | Fact
  [12:8:1.0] 1GL machine language | Only 0 and 1; the only language a computer runs directly; no translator; machine code; based on Boolean algebra
  [12:8:1.1] 2GL assembly | Mnemonics; converted by an assembler (not a compiler)
  [12:8:1.2] 3GL high-level | FORTRAN (Formula Translation, IBM, scientific, first HLL 1957), COBOL (business), BASIC (Beginner's All Purpose Symbolic Instruction Code), PASCAL, C, C++ (Stroustrup), Java, Python
[12:8:2] - **BASIC** is a **procedural** language (with C, FORTRAN, PASCAL).
[12:8:3] - **Cobra, Python, Squirrel, Java** are all computer languages; **Paint brush** and **FAST** are NOT.
[12:8:4] - APPSC 2019 odd-one-out answer: **Python**.
[12:8:5] # Translators and Logic Design
[12:8:6] TABLE head: Term | Meaning
  [12:8:6.0] Compiler | System software; translates the whole program at once (faster execution)
  [12:8:6.1] Interpreter | Translates and runs line by line (easier debugging)
  [12:8:6.2] Algorithm | Finite step-by-step procedure
  [12:8:6.3] Flowchart | Pictorial form of an algorithm (APPSC 2019)
  [12:8:6.4] Pseudocode | English-like text outline
  [12:8:6.5] Source code | The written program
[12:8:7] - Flowchart symbols: **oval** = start/end, **parallelogram** = input/output, **rectangle** = process, **diamond** = decision.
[12:8:8] # Number Systems
[12:8:9] - Binary (base 2), octal (8), decimal (10), **hexadecimal** (16, digits 0–9 and A–F).
[12:8:10] - (1010)₂ = 10; **(FF)₁₆ = 15 × 16 + 15 = 255**.
[12:8:11] # Logic Gates and Boolean Algebra
[12:8:12] - **Universal gates: NAND and NOR**; basic gates: AND, OR, NOT.
[12:8:13] - **OR**: output 1 if any input is 1; 0 only when all inputs are 0. **XOR**: 1 when inputs differ.
[12:8:14] - Boolean: A + A = A; A·A′ = 0; **De Morgan: (A + B)′ = A′ · B′**.
