  (2) RAM is like a hard disc storage
  (3) RAM is a volatile memory
  (4) Information stored in RAM is gone when the computer
explanation (OCR): Random Access Memory (RAM) is the hardware in a computing device that provides temporary storage for the operating system (OS), software programs and any other data in current use so they're quickly available to the device's processor. Random access memory is considered part of a computer's primary memory. It is much faster to read from and write to than secondary storage, such as hard disk drives (HDDs), solid-state drives (SSDs) or optical drives. When the computer is rebooted, the OS and other files must be reloaded into RAM, usually from an HDD or SSD. Hence, statement of option (b) is not true about RAM, while statements of other three options are correct.
