h: Basics
b: **Malware** (malicious software) = single word for viruses, worms, trojans etc.: software **designed to disrupt, damage or gain unauthorised access** to a computer (not merely buggy software).
b: **VIRUS** = "**Vital Information Resources Under Siege**"; a program that **replicates itself**, **attaches to files** and spreads from computer to computer – enters via **images, audio/video files, downloads, attachments**; infects storage such as a **pen drive**, not a display or keyboard.
b: **Bug** = a fault in a program that stops it working correctly.
b: **Father of computer virology:** **John von Neumann** (1949 theory of self-reproducing automata).
h: Types → behaviour → example
t: Type | Defining behaviour | Example
   row: **Virus** | **Attaches to files**, reproduces and spreads; user must run the infected file | Brain, Michelangelo
   row: **Worm** | Uses the **network to send copies of itself without user action**; does **not** need to attach to a program | WannaCry, Morris
   row: **Trojan** | **Looks like legitimate software**, tricks the user into installing it, then acts like a virus/worm; no self-replication; backdoor | Zeus
   row: Ransomware | Encrypts files, demands ransom (often crypto) | WannaCry, Petya
   row: Spyware | Secret surveillance; steals passwords, banking data | Pegasus
   row: Adware | Unwanted ads; bundled with free/pirated software | Fireball
   row: **Rootkit** | Administrator-level access; **modifies the host OS to hide malware**; hardest to detect | Stuxnet parts
   row: **Stealth virus** | Designed to **hide from antivirus** detection | –
   row: Keylogger | Records keystrokes (passwords, PINs, OTPs) | DarkHotel
   row: Botnet | Network of hijacked "zombie" devices for DDoS, spam | Mirai (IoT)
b: **Antivirus** software: McAfee, Kaspersky, Avast, **Webroot**, Norton – **Rootkit is malware, not antivirus**; Webroot is not a virus.
b: Viruses, worms and trojans all threaten **electronic payment systems**.

h: Purpose

   row: 66E / 66F | Privacy / **cyber terrorism (life)**
   row: 67 / 67A | Obscene / sexually explicit
