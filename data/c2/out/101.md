## SEC 5:12:4 | Memory
### Units
- ★ **1 byte = 8 bits**
- **Nibble** — **4 bits**
### Primary memory
- ★ **RAM** — **Random Access Memory**; short-term, **lost when the computer is turned off** (temporary)
- ★ **ROM** — **Read-Only Memory**: data can only be read; **non-volatile**, the **permanent** memory, kept when power goes off
  - other non-volatile memory: **flash** (SSDs, USB drives), hard disk drives
- ★ **ROM** is a memory, **not a computer language**
- ★ **Cache memory** — **fastest**, **shortest access time**; accessed by the microprocessor faster than RAM, highest bandwidth
- **SRAM** — used as **cache**; **DRAM** — main memory

- Speed order: **registers** > **cache** > **RAM** > **magnetic tape**

# ROW 5:13 | Networks and the internet - LAN/WAN, protocols, IP, DNS, web technologies
## SEC 5:13:0 | Internet firsts
- **ARPANET** (**1969**) — developed under the **US Department of Defense**; forerunner of the Internet
- **ERNET** (**1986**) → **VSNL** public internet in India on **15 August 1995** → **Satyam Infoway**, first private ISP (**1998**)
- ★ **VPN** (Virtual Private Network) — network across the **public internet** giving users access to their **organisation's network**; secure, **encrypted** connection
## SEC 5:13:1 | Network types & topologies
- ★ **Ethernet** — example of a **LAN**; network protocol **IEEE 802.3**
- **WAN** — links LANs in **different cities** (e.g. Mumbai, Bengaluru, New Delhi); **MAN** — a city; **PAN** — personal devices
- **VPN** — an **encrypted tunnel** over a public network; improves privacy
- **Star topology** — a failed **node** is only isolated; a **hub** failure stops the whole network
## SEC 5:13:2 | OSI model (top first)
### Layers (top to bottom)
| Layer | Note |
|---|---|
| **Application** | |
| **Presentation** | **encryption, compression and formats** |
| **Session** | |
| **Transport** | **TCP** and **UDP** |
| **Network** | **router** (routes by IP) |
| **Data Link** | **switch** (forwards frames by **MAC address**) |
| **Physical** | **modem** (modulates and demodulates signals), hub |

- **Hub** — broadcasts to all ports; **modem** — converts signals; modem is **not** a Transport-layer device
### Protocols and bodies
- **DHCP** — assigns **IP addresses automatically**; **DNS** — domain names → IP addresses; **TCP** — reliable delivery
- **NIXI** (**2003**) — not-for-profit under **MeitY**; runs internet exchange points, the **.in registry** and **IRINN**
- Site opening on one ISP but not another — **ISP-level DNS poisoning**, **HTTP interception** or **SNI filtering**
- **Naidu–Sunil Mittal** talks for Andhra Pradesh — **last-mile connectivity**, **data centres**, an **undersea cable landing station**
## SEC 5:13:3 | Protocols
- ★ **FTP** — **File Transfer Protocol**: exchanging files over the Internet
- **IMAP** — keeps mail **on the server**, synchronised across devices; **POP3** usually **deletes** mail from the server after download
